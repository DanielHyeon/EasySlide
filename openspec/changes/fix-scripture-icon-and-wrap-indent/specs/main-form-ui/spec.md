# 말씀 항목과 줄바꿈 표시

## ADDED Requirements

### Requirement: 예배 순서와 미리보기 제목의 말씀 아이콘

WinForms 메인 화면은 이름에 ‘말씀’이 들어간 폴더의 곡 또는 가사 끝에 성경 구절 출처가 있는 곡을 예배 순서와 미리보기 제목에서 같은 성경책 아이콘으로 표시해야 한다(SHALL).

#### Scenario: 일반 찬양 폴더에 저장된 말씀을 선택한다

- **GIVEN** 복음성가 폴더의 곡 가사가 `(사도행전 9:31)`로 끝난다.
- **WHEN** 운영자가 예배 순서에서 그 곡을 선택한다.
- **THEN** 예배 순서 행과 미리보기 제목에 모두 성경책 아이콘이 보이고 곡의 저장 폴더와 유형은 유지된다.

#### Scenario: 일반 찬양을 선택한다

- **WHEN** 말씀 폴더 밖에서 성경 구절 출처로 끝나지 않는 찬양을 선택한다.
- **THEN** 예배 순서 행과 미리보기 제목에 찬양 아이콘이 보인다.

### Requirement: 왼쪽 정렬 본문의 자동 줄바꿈 들여쓰기

왼쪽 정렬 본문은 저장된 `Indent Word Wrapped Text` 옵션을 따라야 하며, 저장된 값이 없으면 들여쓰기를 꺼야 한다(SHALL).

#### Scenario: 설정을 저장한 적이 없는 본문이 두 줄로 넘어간다

- **WHEN** 화면 너비 때문에 왼쪽 정렬 본문의 한 줄이 두 줄로 나뉜다.
- **THEN** 첫 줄과 이어지는 줄의 시작 위치가 같다.

#### Scenario: 운영자가 들여쓰기를 켠다

- **WHEN** 들여쓰기를 켜고 같은 본문을 같은 너비로 표시한다.
- **THEN** 자동 줄바꿈으로 이어지는 줄 앞에만 공백 두 칸을 붙인다.

### Requirement: 폴더 정렬 버튼의 크기와 위치

메인 화면의 새 모양은 폴더 정렬 아이콘을 도구 모음 아이콘 칸의 3분의 2 크기로 그리고 버튼을 옆 폴더 선택 상자의 높이와 위치에 맞춰야 한다(SHALL).

#### Scenario: 곡 번호순 정렬 버튼이 눌린 상태다

- **WHEN** Windows 배율 100%에서 곡 번호순을 선택한다.
- **THEN** 24픽셀 아이콘 칸에 16픽셀 아이콘이 보이고 버튼 테두리는 폴더 선택 상자 아래로 내려가지 않는다.

#### Scenario: 고대비 모드가 새 모양을 해제한다

- **WHEN** 고대비 모드에서 기존 모양을 사용한다.
- **THEN** 해당 도구 모음은 디자이너에 지정된 크기로 표시된다.

# 말씀 항목 아이콘, 줄바꿈 들여쓰기, 정렬 버튼 아이콘 (fix-scripture-icon-and-wrap-indent)

## 왜
사용자 요청(2026-11-18):
1. 텍스트를 표시할 때 첫 줄만 왼쪽으로 치우쳐 보임.
2. 예배 순서(왼쪽 아래)와 미리보기 제목(오른쪽 위)에서 '우리교회말씀'이 악보(♫) 아이콘 → 성경책 아이콘으로.
3. 폴더 선택 상자 옆 정렬(필터) 버튼 아이콘이 너무 큼.
4. `DrawTextCore`, `ShowThumbImage`의 버그·성능·리팩토링 점검.

## 원인과 결정
1. 버그가 아니라 옵션 'Indent Word Wrapped Text'(`WordWrapLeftAlignIndent`, 기본 켜짐). 왼쪽 정렬에서 화면 폭 때문에 넘어간 줄 앞에 공백 두 칸을 붙여서 첫 줄이 튀어나와 보였음.
   → 사용자 결정: 옵션 끄기. 기본값을 끔(코드·레지스트리 기본값), 이 PC의 설정도 0으로 바꿈. 옵션 창에서 다시 켤 수 있음.
2. '우리교회말씀'(SONGID 10245)은 복음성가 폴더에 '찬양'으로 저장된 성경 구절(사도행전 9:31)이라 찬양 아이콘이 나옴. 기존 규칙(D25: 폴더 이름에 '말씀')은 해당 폴더가 없어 적용되지 않았음.
   → 사용자 결정: 가사가 성경 구절 표시 `(책 장:절)`로 끝나는 곡을 말씀 항목으로 봄. DB 전체에서 이 곡 1곡만 해당(후보 60곡 중). 아이콘은 성경 항목과 같은 성경책(`bible`)으로 바꿈(이전 `verse_card`). 데이터는 바꾸지 않음.
3. 툴바 칸 크기(24 px)로 그려서 주변의 16 px 아이콘(찾기 상자, 목록 행)보다 컸음 → 칸의 2/3(100 %에서 16 px).
   추가 요청("Sort by Song number 필터 아이콘이 큼"): 제목 순이 아니면 버튼이 눌린(Checked) 상태로 그려지는데, 버튼이 36 px로 옆 콤보(28 px)보다 커서 파란 테두리 상자가 콤보 아래까지 내려왔음 → 새 모양에서 이 줄의 툴바(폴더 정렬 버튼, 찬양집 버튼들)를 콤보와 같은 높이·위치로 맞춤. 고대비로 새 모양이 꺼지면 디자이너 크기로 되돌림.
4. 점검 결과
   - `ShowThumbImage`: 호출하는 곳이 없는 죽은 코드(썸네일은 `ImageCanvas`가 그림). 외부 PowerPoint 미리보기 경로도 틀렸고(번호 폴더 없음, .ppt만), 스트림을 닫은 뒤 그림을 읽음 → 관련 도우미와 함께 삭제(ee82a6c).
   - `DrawTextCore`: 그리기 버퍼와 Graphics는 화면 컨트롤이 소유·재사용(누수 없음), 실패 시에도 보이는 층이 깨지지 않게 이미 정리돼 있음. `DisplayTextByWidthOneLine`에서 쓰지 않는 줄 폭 측정(줄마다 MeasureString 1회)을 삭제.
   - 남은 개선 후보(이번에 고치지 않음): `DrawOneLine` 오버로드 5개 연쇄 → 선택 인자 하나로; 인터레이스 모드 글꼴 축소 루프가 1pt씩 MeasureString(큰 글꼴에서 수십 회) → 이분 탐색; 들여쓰기 옵션을 켰을 때 코드(악보 기호) 위치가 가사와 다른 글꼴의 공백 폭으로 밀림.

## 검증
- 정규식: DB 사본 전체에서 '우리교회말씀' 1곡만 일치.
- 앱 실행(이 PC): 예배 순서 행과 미리보기 제목 행에 성경책 아이콘, 미리보기 본문 네 줄이 같은 왼쪽 위치에서 시작, 정렬 버튼 아이콘 축소. DB·예배 목록 변화 없음, 레지스트리는 실행 전과 같음(들여쓰기 0은 실행 전에 바꾼 값).

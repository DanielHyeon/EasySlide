## Purpose

WinForms와 WPF에서 예배 순서, 미리보기 및 송출을 조작하는 사용자가 같은 명령을 같은 위치와 그림으로 알아볼 수 있도록 한다.

## ADDED Requirements

### Requirement: 공통 운영 화면
WPF 메인은 현대화한 FrmMain과 동일한 조작 영역, 명령 아이콘 및 상태 구분을 제공해야 한다 (SHALL).

#### Scenario: 도구 모음
- **WHEN** 운영자가 창 폭을 바꾼다
- **THEN** 한 줄의 도구 모음에서 여유가 있으면 편집 명령의 아이콘과 이름을 함께 표시하고 좁아지면 글자를 접는다

#### Scenario: 미리보기와 송출
- **WHEN** 운영자가 미리보기와 송출 상태를 확인한다
- **THEN** 제목과 명령은 각 영역의 파란색 또는 주황색 머리줄 안에 있고 하단 이동 버튼은 항목 이동과 슬라이드 이동을 서로 다른 화살표로 구분한다

#### Scenario: 목록과 화면
- **WHEN** 운영자가 곡이나 예배 순서를 탐색한다
- **THEN** 곡 이름과 번호, 예배 순서 작업, 하단 샘플 화면은 WinForms의 위치와 역할을 따른다

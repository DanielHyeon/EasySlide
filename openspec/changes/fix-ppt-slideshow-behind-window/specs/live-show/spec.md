# live-show

## ADDED Requirements

### Requirement: 송출 중인 PPT 슬라이드는 출력 모니터의 다른 창에 가려지지 않는다

모니터 둘 방식의 쇼에서 PPT 항목이 송출되면, 앱은 그 슬라이드 쇼를 출력 모니터의 다른 앱 창들 위에 보이게 해야 한다(SHALL). 이때 메인 화면의 키보드 포커스를 옮기면 안 된다(SHALL NOT).

#### Scenario: 출력 모니터에 다른 앱의 창이 있다

- **GIVEN** 출력 모니터에 다른 앱의 창이 최대화되어 있고 쇼가 진행 중이다
- **WHEN** PPT 항목을 송출로 보낸다
- **THEN** 출력 모니터에 그 항목의 슬라이드가 보인다
- **AND** 메인 화면이 포커스를 유지한다

#### Scenario: 앱이 전경이 아닐 때 항목이 바뀐다

- **GIVEN** 쇼가 진행 중이고 다른 앱이 전경이다
- **WHEN** 리모컨, 단축키 등으로 PPT 항목이 송출된다
- **THEN** 출력 모니터에 그 항목의 슬라이드가 보인다

#### Scenario: PPT 항목 다음에 가사 항목

- **WHEN** PPT 항목 다음에 가사 항목을 송출한다
- **THEN** 출력 모니터에 가사가 보이고 슬라이드는 보이지 않는다

#### Scenario: PPT 항목 위의 알림과 참조 표시

- **WHEN** PPT 항목이 송출 중일 때 알림이나 참조 표시를 켠다
- **THEN** 슬라이드 위에 알림, 참조 표시가 보인다

### Requirement: 쇼가 끝나면 슬라이드 쇼 창이 화면을 덮은 채 남지 않는다

쇼가 끝난 뒤 출력 모니터에 앱이 올려 둔 "항상 위" 창이 남으면 안 된다(SHALL NOT).

#### Scenario: 쇼를 끝낸다

- **GIVEN** PPT 항목이 송출 중이다
- **WHEN** 쇼를 끝낸다
- **THEN** 출력 모니터에는 쇼를 시작하기 전에 있던 창들이 보인다

### Requirement: 슬라이드 쇼를 앞으로 올리지 못하면 알린다

앱이 슬라이드 쇼 창을 올리지 못하면 기록하고 메인 화면의 알림 칸에 알려야 한다(SHALL).

#### Scenario: 올리기가 실패한다

- **WHEN** 슬라이드 쇼 창의 순서를 바꾸는 호출이 실패한다
- **THEN** 알림 칸에 오류가 나오고 기록에 남는다

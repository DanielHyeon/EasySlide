## Context

레거시 파일에는 찬양집 곡 식별자와 예배 순서 헤더 메모가 있다. 기존 WPF 서비스에는 검색, 목록 추가, 폴더 이동 명령이 있다.

## Decisions

기존 저장 형식을 확장하고 필드가 없는 이전 JSON도 읽는다. 폴더 변경이 성공한 뒤 이동표로 바로가기를 갱신한다. 성경 책 필터는 검색 개수 제한 전에 적용한다. 검색 결과에서 곡 ID를 사용하고 예배 순서에 추가할 때만 큐를 바꾼다.

파일 메뉴에서 외부 ESW를 가져오면 독립적인 예배 순서로 취급한다. 같은 이름의 세션이나 메모가 있으면 새로운 이름을 부여하고 저장 전까지 최근 목록에 올리지 않는다. 명시적으로 비운 메모도 다음에 다시 열 때 유지한다.

상세 검색 창은 검색을 마쳤을 때 결과와 데이터베이스 경로를 메인 창에 전달한다. 도구 모음의 빠른 찾기는 활성 폴더와 전체 텍스트 필드를 사용한다. UI에서 곡을 미리볼 때 예배 순서의 선택과 현재 송출은 유지한다.

폴더 순서를 확정하기 전에는 데이터베이스를 갱신하지 않는다. 재활용 폴더 0번은 이동 목록에서 제외한다. 설정 파일에 A/B/C를 기록할 수 없으면 역순 매핑으로 원래 폴더 번호를 복원하고 목록을 다시 읽는다.

전역 위·아래 방향키는 송출 중 이전·다음 슬라이드 명령을 사용한다. 전역 Ctrl 방향키만 사용하도록 지정한 경우에는 Ctrl을 누를 때만 등록한다. 기존 사용자 단축키와 같은 조합은 중복 등록하지 않는다.

## Risks / Trade-offs

동명이곡과 구형 자료는 서로 구별하며 병합으로 현재 세션의 메모가 바뀌지 않게 한다. 검증에는 임시 SQLite·JSON·ESW를 사용한다.

## Purpose

예배 운영자가 기존 자료를 WPF로 가져와 찬양집을 만들고 곡 또는 성경 본문을 찾으며 송출을 조작할 때 지켜야 하는 동작을 정의한다.

## ADDED Requirements

### Requirement: 찬양집 곡 식별

WPF는 찬양집을 저장하고 다시 열 때 각 항목의 SongId를 보존해야 한다(SHALL). 기존 파일에 ID가 없고 제목·번호로 한 곡을 식별할 수 없으면 추가와 문서 생성을 중단한다.

#### Scenario: 같은 제목과 번호의 두 곡을 저장 후 다시 연다

- **WHEN** 같은 제목과 번호의 두 곡을 저장 후 다시 연다.
- **THEN** 각 항목이 원래 곡 ID를 유지한다.

### Requirement: 가사가 있는 찬양집 문서

메인 찬양집의 HTML·RTF 문서 생성은 목록 순서대로 제목과 가사 본문을 내보내야 한다(SHALL).

#### Scenario: HTML 또는 RTF 문서를 생성한다

- **WHEN** HTML 또는 RTF 문서를 생성한다.
- **THEN** 각 곡의 제목과 줄바꿈이 보존된 가사가 나온다.

### Requirement: 기존 예배 진행 메모

WPF는 ESW의 ListHeader/Notes를 읽어 미리보기의 메모 보기와 편집 창에 표시해야 한다(SHALL). 메모만 있는 세션도 열 수 있고 편집과 지우기의 결과를 유지한다.

#### Scenario: 메모가 들어 있는 ESW를 세션으로 연다

- **WHEN** 메모가 들어 있는 ESW를 세션으로 연다.
- **THEN** 그 세션의 메모를 확인하고 편집할 수 있다.

### Requirement: 상세 검색과 예배 순서

Ctrl+F의 상세 검색은 결과를 메인 창에 전달하고 선택한 곡 ID로 미리보기와 예배 순서 추가를 실행해야 한다(SHALL). 미리보기는 큐 선택과 현재 송출을 유지한다.

#### Scenario: Ctrl+F에서 찾은 곡을 선택한다

- **WHEN** Ctrl+F에서 찾은 곡을 선택한다.
- **THEN** 운영자가 결과에서 미리보기와 예배 순서 추가를 할 수 있다.

### Requirement: 곡 찾기 조건

상세 검색은 선택한 폴더와 필드, 양수 곡 번호, 수정일 범위를 반영하고 다음 상세 검색에 날짜 설정을 복원해야 한다(SHALL). 도구 모음의 빠른 찾기는 활성 폴더 전체에서 검색한다.

#### Scenario: 폴더나 검색 필드를 해제하거나 번호 0을 검색하고 날짜를 지정한다

- **WHEN** 폴더나 검색 필드를 해제하거나 번호 0을 검색하고 날짜를 지정한다.
- **THEN** WinForms와 일치하는 결과와 안내를 제공하고 다음 찾기에 날짜 범위를 복원한다.

### Requirement: 성경 책 검색 범위

성경 검색은 전체 성경 또는 선택한 책을 대상으로 하며 결과 개수 제한 전에 책 필터를 적용해야 한다(SHALL).

#### Scenario: 특정 책 또는 전체 성경을 지정해 본문을 찾는다

- **WHEN** 특정 책 또는 전체 성경을 지정해 본문을 찾는다.
- **THEN** 지정한 범위 안의 구절만 검색한다.

### Requirement: 폴더 순서 변경

편집 메뉴에서 일반 곡 폴더의 새 순서를 확정하면 곡과 선택한 폴더, A/B/C 바로가기가 같은 폴더를 유지해야 한다(SHALL). 0번 재활용 폴더는 이동 대상에서 제외한다.

#### Scenario: 편집 메뉴에서 폴더를 옮긴다

- **WHEN** 편집 메뉴에서 폴더를 옮긴다.
- **THEN** 폴더 순서가 바뀌고 A/B/C 바로가기는 원래 폴더를 가리킨다.

### Requirement: 전역 방향키

전역 방향키 옵션을 켜면 위·아래 방향키 및 Ctrl과의 조합이 이전·다음 송출 명령으로 한 번씩 등록되어야 한다(SHALL).

#### Scenario: 전역 방향키만 켠 상태에서 Ctrl을 누르고 방향키를 입력한다

- **WHEN** 전역 방향키만 켠 상태에서 Ctrl을 누르고 방향키를 입력한다.
- **THEN** 송출 슬라이드가 해당 방향으로 한 번 이동한다.

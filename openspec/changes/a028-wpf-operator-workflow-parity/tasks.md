## 검증 결과

- Release 솔루션 테스트를 프로젝트별로 순차 실행했다. WPF 2,632개, WinForms 235개, 분석기 20개가 통과했다.
- Windows에서 실제 WPF 메인 창을 임시 설정, 배포용 DB 복사본, 테스트 프로세스 전용 HKCU로 열었다. 메모 보기와 닫기, 폴더 정렬 창에서 이동 후 취소, 상세 검색 결과를 메인 창에서 선택해 미리보기와 목록 추가를 실행했다.
- 임시 SQLite와 잠근 설정 파일로 폴더 정렬 실패 시 DB의 폴더 번호, 바로가기, 선택과 곡 목록 복원을 확인했다. 파일 내보내기와 성경 범위는 생성된 HTML·RTF 본문과 임시 성경 SQLite 결과를 비교했다.

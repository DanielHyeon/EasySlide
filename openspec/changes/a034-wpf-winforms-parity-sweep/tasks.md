## 남은 차이

- [ ] 2개 언어 곡에서 영역 2가 먼저 끝난 화면은 영역 1이 본문 전체 자리를 쓴다. WinForms는 영역 2 위의 자리에 그대로 둔다(세로 정렬이 위쪽이 아니면 위치가 다르다).
- [ ] 글자 크기가 약간 다르다. 50pt·너비 2048에서 WinForms 약 138픽셀, WPF 143픽셀.
- [ ] 첫 줄 시작 위치가 WPF에서 화면 높이의 2.2%만큼 높다(WinForms `ShowTopBorderSize`).
- [ ] 페이지 안의 빈 줄: WinForms는 높이 0, WPF는 한 줄 높이.
- [ ] 인터레이스 표시와 영역 2의 세로 위치 규칙은 옮기지 않았다.

- [ ] 줄인 글꼴은 미리보기와 송출 화면에만 적용된다. 스테이지 모니터는 자체 글꼴 설정을 그대로 쓴다.
- [ ] 목록 관리 창에 "PraiseBook으로 저장"과 "템플릿으로 저장" 버튼이 없다. 세션 템플릿 저장은 주 메뉴에 있다.
- [ ] 코드를 표시해도 페이지를 다시 나누지 않고 글자를 줄인다. WinForms는 화면 수를 늘린다.
- [ ] 텍스트 파일은 맞춤 설정과 무관하게 공백만 있는 줄에서 문단을 나눈다.
- [ ] FrmEditItem은 첫 절 표시 앞에 가사가 있는 실제 곡 15개의 저장을 거부한다. WPF 편집기는 저장한다.
- [ ] 암호가 걸린 PPT와 `.pptm` 파일은 실행으로 확인하지 않았다.

## ADDED Requirements

### Requirement: 네이티브 호출의 결과와 상태 일치
두 앱은 Windows API의 실패가 성공으로 기록되는 것을 방지해야 한다(SHALL).

#### Scenario: Windows가 송출 전원 요청을 거절함
- **WHEN** 상태 변경 요청이 실패하고 같은 설정이 다시 적용되면
- **THEN** 실제 성공할 때까지 다음 설정 적용 시 요청할 수 있다.

#### Scenario: 목록 그리기 또는 파일 작업 실패
- **WHEN** Windows가 그리기나 파일 작업 실패를 반환하면
- **THEN** 목록은 기본 그리기로 복구하고 파일 작업은 성공을 보고하지 않는다.

### Requirement: 구형 파일 숫자 기본값 보존
두 앱은 파싱 실패 시 기존 수치 기본값을 유지해야 한다(SHALL).

#### Scenario: 유효하지 않은 구절 번호
- **WHEN** 구형 악보 레코드에 숫자가 아닌 줄 번호가 있으면
- **THEN** 기존의 0번 줄 의미를 보존한다.

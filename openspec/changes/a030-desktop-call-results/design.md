## 동작

송출 창은 Windows가 수락한 전원 상태만 기억한다. 화면 보호기 메시지 필터는 독립적으로 정리한다. 장치 정보나 키 상태를 얻지 못하면 잘못된 대상에 입력을 전달하지 않는다. Office 설치 경로는 관리형 읽기 전용 RegistryKey와 명시적 레지스트리 뷰를 사용한다. 목록 그리기에서 실패한 너비는 캐시에 넣지 않고 기존 기본 그리기 경로를 이용한다.

전원 상태는 동일 UI 스레드에서 새 송출 창으로 이어진다. 실패하면 5초 뒤 최신 요청으로 다시 시도한다. 팝업 활성화 통지는 Windows 규약상 반환값을 사용하지 않는 이유를 호출부에 표시했다. [WM_NCACTIVATE](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-ncactivate)

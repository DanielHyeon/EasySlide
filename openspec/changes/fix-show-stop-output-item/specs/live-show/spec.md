# live-show

## ADDED Requirements

### Requirement: 쇼를 끝내도 송출 단의 항목 정보는 송출 단에 보이는 항목과 일치한다

모니터가 둘인 환경에서 쇼를 끝낸 뒤, 앱이 기억하는 송출 항목(종류, 목록 안의 위치, 슬라이드 번호)은 송출 단에 실제로 올라가 있는 항목과 일치해야 한다(SHALL). 쇼 도중 예배 순서 목록이 바뀌었어도 마찬가지다.

#### Scenario: 쇼 도중 송출 항목을 옮긴 뒤 쇼를 끝낸다

- **GIVEN** 모니터가 둘이고, 예배 순서의 한 항목이 쇼에서 나가고 있다
- **WHEN** 그 항목을 목록에서 위로 옮기고 쇼를 끝낸다
- **THEN** 앱이 기억하는 송출 위치는 옮겨진 뒤의 줄이다
- **AND** "현재 항목 다시 시작"을 누르면 같은 항목이 다시 올라온다
- **AND** 예배 순서 목록의 송출 표시가 그 줄에 있다

#### Scenario: 목록을 바꾸지 않고 쇼를 끝낸다

- **WHEN** 쇼를 시작하고 슬라이드를 몇 장 넘긴 뒤 쇼를 끝낸다
- **THEN** 송출 단은 같은 항목의 같은 슬라이드를 보여 준다 (이 수정 전과 같다)

#### Scenario: 모니터가 하나

- **GIVEN** 모니터가 하나다
- **WHEN** 쇼를 끝낸다
- **THEN** 이 수정 전과 똑같이 동작한다

### Requirement: 송출 창이 스스로 닫혀도 메인 화면은 쇼가 끝난 것을 안다

모니터가 둘인 환경에서 송출 창이 메인 화면의 조작 없이 닫히면, 메인 화면은 쇼 종료 처리를 정확히 한 번 실행해야 한다(SHALL). 쇼 버튼이 눌린 채로 남으면 안 된다(SHALL NOT).

#### Scenario: 송출 창을 직접 닫는다

- **GIVEN** 모니터가 둘이고 쇼가 진행 중이다
- **WHEN** 송출 창이 스스로 닫힌다 (창 닫기 등)
- **THEN** 메인 화면의 쇼 버튼이 꺼진 상태가 되고, 예배 순서 목록의 표시가 갱신된다
- **AND** 그 뒤 쇼 버튼을 누르면 쇼가 정상으로 다시 시작된다

#### Scenario: 메인 화면에서 끝낸다

- **WHEN** 메인 화면의 쇼 버튼이나 F12, 송출 창의 Esc로 쇼를 끝낸다
- **THEN** 쇼 종료 처리는 한 번만 실행된다 (두 번 실행되거나 서로를 다시 부르지 않는다)

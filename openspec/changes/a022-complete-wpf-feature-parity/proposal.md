## Why

Several WPF controls look like their WinForms counterparts but dispatch different operations. Operators also need the same text-file presentation and monitor geometry when they open an existing worship list.

## What Changes

- Inventory main menu actions and application windows against their WinForms implementations.
- Restore missing operator commands and connect them to their WPF execution paths.
- Apply text and display settings consistently across preview and audience output.

## Capabilities

### New Capabilities

- `operator-feature-parity` covers main console command behavior and presentation of worship items.

## Impact

WPF main window, live projection, settings, library management and isolated regression tests.

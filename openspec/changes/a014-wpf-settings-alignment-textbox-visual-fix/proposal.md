# a014-wpf-settings-alignment-textbox-visual-fix 제안서

## 배경

WPF 메인 화면의 설정/서식 영역에서 `Left`, `Center`, `Right` 정렬 컨트롤이 오른쪽으로 치우쳐 보이고, 설정 영역의 여러 `TextBox` 입력값 하단이 잘려 보인다는 보고가 있었다. 이 문제는 송출 로직 자체보다 XAML 스타일과 설정 패널 배치 품질에 가까운 시각 회귀다.

## 목표

- 설정/서식 영역의 좌·중·우 정렬 버튼을 같은 기준선과 균등한 폭으로 배치한다.
- 설정 영역의 숫자/이름/경로 입력 `TextBox`에서 글자 하단이 잘리지 않도록 높이와 내부 여백을 보정한다.
- 공통 `EsTextBox` 템플릿도 하단 잘림을 만들지 않도록 안전하게 수정한다.
- XAML 구조 테스트와 빌드로 회귀를 검증한다.

## 비목표

- 정렬 명령의 저장/송출 로직을 변경하지 않는다.
- Live Show 렌더링 좌표, 글꼴 크기, 배경 선택 로직을 변경하지 않는다.
- 별도 설정 창의 정보 구조를 재설계하지 않는다.

## 수용 기준

- 전역 가사 정렬과 항목별 정렬 버튼이 고정 폭 3열 또는 동일 폭 배치로 표시되어 한쪽으로 밀려 보이지 않는다.
- 설정 영역의 모든 직접 입력 `TextBox`는 충분한 최소 높이와 수직 여백을 가져 하단 글리프가 잘리지 않는다.
- `EsTextBox.Default`/`Search` 템플릿의 `PART_ContentHost`가 텍스트를 클리핑하지 않는 방식으로 배치된다.
- `dotnet test` 또는 영향 범위 테스트가 통과한다.

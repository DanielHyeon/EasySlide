## ADDED Requirements

### Requirement: 입력 크기에 맞는 장치 및 파일 처리
앱은 입력 개수를 임의의 고정 배열 크기로 제한하지 않아야 한다(SHALL).

#### Scenario: 기존 슬롯 수 초과
- **WHEN** 카메라 포맷, 파일 또는 곡 번호가 기존 슬롯 수를 넘으면
- **THEN** 기존 선택 순서대로 유효한 항목에 접근할 수 있다.

### Requirement: 제한된 조회 및 내보내기
앱은 검색 한도와 기존 문서 출력 규칙을 보존하면서 불필요한 목록과 전체 파일 복사를 제거해야 한다(SHALL).

#### Scenario: 대량 입력
- **WHEN** 선택 목록, 이미지, 가사 또는 성경 데이터가 커지면
- **THEN** 동일한 선택, 결과 순서와 출력 형식을 유지한다.

## 검증 결과

- 변경 전 WPF 전달 테스트 2건이 실패했다. 변경 후 활성 명령은 입력을 즉시 소비하고 실제 WPF Dispatcher에서도 UI 스레드가 큐를 처리할 때 실행됐다.
- WinForms에서 기능키·방향키·미디어 처리를 모두 연결하고 F3을 1,000회 눌렀다 뗀 결과 UI 등록은 0건이었다. Ctrl+방향키 단독 설정과 F9·F10의 활성·비활성 전달 정책도 통과했다.
- 합성 Windows 콜백에서 좌우 클릭의 Down, Up, Click, ClickExt가 각각 한 번 발생했다. 훅 해제 오류 후 동일 핸들 재시도와 x64 키보드 24바이트·마우스 32바이트 배치를 확인했다.
- Release 빌드 성공. 테스트 프로세스의 HKCU를 임시 경로로 리디렉션한 전체 실행에서 WinForms 235개, WPF 2,489개, 분석기 20개가 통과했다. 총 2,744개, 실패 및 건너뜀 0개. 실제 송출 장치 입력은 검증 범위에서 제외했다.

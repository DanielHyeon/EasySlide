## ADDED Requirements

### Requirement: Axicultuss 본창 송출 칸의 자막 탭

시스템 SHALL Axicultuss(WinForms) 본창의 송출 칸 맨 위에 `[라이브] [자막]` 탭 줄을 두고, 자막 탭에 Axicultus와 같은 카메라 하단 자막 화면(공용 라이브러리)을 보여 준다. 탭 줄은 본창이 뜰 때부터 보이고 라이브 탭이 골라져 있다. 자막 탭을 고르면 송출 칸 자리에 자막 화면이 보이고 미리보기 칸과 왼쪽 열은 그대로 보인다. 탭을 바꾸어도 자막의 따라가기와 송출은 멈추지 않는다. 자막 화면을 만들 수 없으면 본창은 탭 줄 없이 평소대로 뜬다. 탭 줄의 송출 스위치는 Axicultus와 같은 규칙이다(라이브 탭에서는 자막이 나가는 중일 때만 보이고 누르면 숨긴다).

#### Scenario: 시작할 때의 탭 줄

- **WHEN** Axicultuss 본창이 뜬다
- **THEN** 송출 칸 맨 위에 탭 줄이 보이고 라이브 탭이 골라져 있으며, 송출 칸은 탭 줄 아래에 평소대로 보이고 자막은 숨김 상태다

#### Scenario: 자막 탭으로 바꾸기

- **GIVEN** 라이브 탭이 보인다
- **WHEN** 운영자가 메뉴 "출력 › 카메라 하단 자막"을 누르거나 F2를 누른다
- **THEN** 송출 칸 자리에 자막 화면이 보이고 미리보기 칸은 그대로 보인다

#### Scenario: 자막 화면을 만들 수 없을 때

- **GIVEN** 자막 화면을 만드는 중에 오류가 난다
- **WHEN** 본창이 뜬다
- **THEN** 본창은 탭 줄 없이 평소대로 뜨고 오류는 기록된다

### Requirement: 회중 화면에 나가는 것을 따라간다

시스템 SHALL 화면 따라가기에서 회중 화면에 실제로 나가는 것을 자막으로 따라간다. 쇼가 돌고 있으면 쇼 창의 항목과 페이지를, 돌고 있지 않으면 본창 송출 칸의 항목과 페이지를 따른다. 찬양·성경·글 항목은 지금 페이지의 글을 자막으로 하고 페이지 목록을 단계로 보여 준다. PowerPoint 항목(.pptx 등)은 파일을 읽어 지금 장의 글이나 악보 줄을 자막으로 한다. 검은 화면인 동안에는 자막이 나가지 않고 대기로 표시된다. 미디어와 간격 항목은 단계가 없다. 자막은 송출 상태를 읽기만 하며, 쇼 창과 송출 로직의 동작을 바꾸지 않는다. 송출이 바뀐 뒤 자막이 따라가기까지는 0.5초를 넘지 않는다.

#### Scenario: 찬양의 다음 페이지

- **GIVEN** 화면 따라가기이고 자막이 나가는 중이며 송출 칸에 3쪽짜리 찬양의 1쪽이 있다
- **WHEN** 운영자가 송출 칸을 다음 페이지로 넘긴다
- **THEN** 자막은 2쪽의 글이 되고 단계 목록의 지금 단계는 2/3이다

#### Scenario: 쇼가 도는 동안의 자동 넘김

- **GIVEN** 쇼가 돌고 있고 자동 넘김이 쇼 창의 페이지를 넘긴다
- **WHEN** 쇼 창이 다음 페이지를 보인다
- **THEN** 자막은 쇼 창이 보이는 페이지의 글이 된다

#### Scenario: 검은 화면

- **GIVEN** 쇼가 돌고 있고 자막이 나가는 중이다
- **WHEN** 운영자가 검은 화면(F9)을 켠다
- **THEN** 자막은 나가지 않고 탭 줄의 스위치는 대기를 표시하며, 검은 화면을 끄면 자막이 다시 나간다

#### Scenario: PowerPoint 항목

- **GIVEN** 화면 따라가기이고 송출 칸에 .pptx 항목의 2장이 있다
- **WHEN** 운영자가 자막 탭을 본다
- **THEN** 단계 목록은 그 파일의 장들이고 지금 단계는 2장이다

### Requirement: 고른 항목의 자막 미리 보기

시스템 SHALL 자막 탭이 보이고 화면 따라가기이며 쇼가 돌고 있지 않을 때, 예배 순서에서 고른 항목을 미리보기의 "송출 칸으로"와 같이 송출 칸에 올려 그 항목의 단계와 자막을 자막 탭에 보여 준다. 쇼가 도는 동안과 라이브 탭에서는 고르기만으로 송출 칸이 바뀌지 않는다. 미디어 항목은 고르기만으로 올라가거나 재생되지 않는다.

#### Scenario: 쇼가 꺼진 동안 고르기

- **GIVEN** 자막 탭이 보이고 화면 따라가기이며 쇼는 돌고 있지 않다
- **WHEN** 운영자가 예배 순서에서 찬양을 고른다
- **THEN** 그 찬양이 송출 칸에 올라가고 자막 탭에 그 페이지 단계와 첫 페이지 자막이 보이며, 회중 화면과 OBS에는 아무것도 나가지 않는다

#### Scenario: 쇼가 도는 동안 고르기

- **GIVEN** 자막 탭이 보이고 쇼가 돌고 있다
- **WHEN** 운영자가 예배 순서에서 다른 항목을 고른다
- **THEN** 송출 칸과 회중 화면과 자막은 그대로다

### Requirement: 키와 메뉴

시스템 SHALL 출력 메뉴에 "카메라 하단 자막"(F2, 라이브·자막 탭 전환)과 "카메라 자막 켜기/끄기"(F6)를 둔다. 두 키는 본창 어디서나, 포커스가 자막 화면 안에 있어도 동작한다. 포커스가 자막 화면 안에 있으면 Space·Esc·화살표·1~4는 Axicultus와 같은 자막의 키이고, 기능 키와 메뉴 단축키는 본창의 키다. 포커스가 자막 화면 밖에 있으면 본창의 키는 지금과 같다. 본창의 기존 단축키·클릭·더블클릭·끌어 놓기는 바뀌지 않는다.

#### Scenario: 라이브 탭에서 F6

- **GIVEN** 자막이 숨김이고 라이브 탭이 보인다
- **WHEN** 운영자가 F6을 누른다
- **THEN** 자막이 나가고 탭 줄에 "눌러서 숨김" 스위치가 나타난다

#### Scenario: 자막 화면에서 F9

- **GIVEN** 포커스가 자막 화면 안에 있다
- **WHEN** 운영자가 F9를 누른다
- **THEN** 본창의 검은 화면이 켜진다

#### Scenario: 송출 칸의 Space는 그대로

- **GIVEN** 라이브 탭이 보이고 포커스가 송출 칸에 있다
- **WHEN** 운영자가 Space를 누른다
- **THEN** 송출 칸이 다음 페이지로 넘어간다(지금과 같다)

### Requirement: 내보낼 곳과 저장

시스템 SHALL Axicultuss에서 자막을 OBS 브라우저 소스와 회중 화면("카메라")으로 내보낸다(자막 서버, OBS 연결, 씬 전환, 내보낼 곳 선택은 Axicultus와 같다). 옛 PowerPoint 형식(.ppt·.pps)은 읽을 수 없다는 안내를 보인다. 자막의 선택(모양, 미리보기 높이)과 OBS 설정, 복구 파일은 Axicultuss 설정 파일이 있는 폴더에 저장하고, 설정 파일 위치를 바꾸는 환경 변수가 있으면 그 폴더를 쓴다. 자막 서버 시작과 OBS 연결은 자막을 처음 쓸 때 한다.

#### Scenario: 저장 위치

- **GIVEN** 설정 파일 위치를 바꾸는 환경 변수가 없다
- **WHEN** 운영자가 자막 글자색을 바꾼다
- **THEN** 선택은 `%APPDATA%\Axicultuss\caption-style.json`에 저장되고 Axicultus의 프로필은 바뀌지 않는다

#### Scenario: 격리 실행

- **GIVEN** 환경 변수가 다른 설정 파일을 가리킨다
- **WHEN** 자막의 선택이 저장된다
- **THEN** 그 설정 파일의 폴더에 저장되고 `%APPDATA%\Axicultuss`는 바뀌지 않는다

#### Scenario: 옛 형식 PowerPoint

- **GIVEN** 송출 칸에 .ppt 항목이 있다
- **WHEN** 운영자가 자막 탭을 본다
- **THEN** 읽을 수 없는 형식이라는 안내가 보이고 자막은 비어 있다

### Requirement: 회중 화면의 카메라 자막

시스템 SHALL 쇼가 도는 동안, 자막이 나가는 중이고 내보낼 곳 "카메라"가 켜져 있으면 회중 화면 아래쪽에 자막을 겹쳐 보여 준다. 모양(폭, 아래 여백, 줄 수, 글자 크기 비율, 배경 상자, 글자색, 악보 줄 높이)은 Axicultus의 카메라 자막과 같다. 자막은 회중 화면에 무엇이 나가고 있든(찬양, 성경, 그림, PowerPoint 쇼) 그 위에 보이고, 수동으로 지정한 송출 영역을 따른다. 검은 화면인 동안, 자막을 숨긴 동안, "카메라"를 끈 동안, 쇼가 돌지 않는 동안에는 보이지 않으며 그때 회중 화면은 자막 기능이 없을 때와 같다. 자막은 마우스와 키보드를 받지 않고 포커스를 가져가지 않는다. 자막을 그릴 수 없으면 쇼는 평소대로 돌고 자막만 회중 화면에 나가지 않는다.

#### Scenario: 쇼 중 자막 켜기

- **GIVEN** 쇼가 돌고 있고 "카메라"가 켜져 있으며 회중 화면에 찬양 1쪽이 있다
- **WHEN** 운영자가 F6으로 자막을 켠다
- **THEN** 회중 화면 아래쪽에 1쪽의 글이 자막으로 보이고, 본창의 키보드 포커스는 그대로다

#### Scenario: 자막 끄기

- **GIVEN** 회중 화면에 자막이 보인다
- **WHEN** 운영자가 자막을 숨긴다
- **THEN** 회중 화면에서 자막이 사라지고 화면은 자막 기능이 없을 때와 같다

#### Scenario: 검은 화면

- **GIVEN** 회중 화면에 자막이 보인다
- **WHEN** 운영자가 검은 화면을 켠다
- **THEN** 회중 화면은 검은 화면만 보이고 자막은 보이지 않는다

#### Scenario: 쇼가 끝남

- **GIVEN** 회중 화면에 자막이 보인다
- **WHEN** 쇼가 끝난다
- **THEN** 자막도 회중 화면에서 사라진다

#### Scenario: "카메라"만 끔

- **GIVEN** 자막이 OBS와 회중 화면에 나가는 중이다
- **WHEN** 운영자가 내보낼 곳 "카메라"를 끈다
- **THEN** 회중 화면의 자막은 사라지고 OBS의 자막은 그대로다

### Requirement: 격리 실행 하네스

시스템 SHALL Axicultuss를 격리한 설정과 데이터 사본으로 실행해 본창과 자막 탭을 자동으로 점검하는 하네스를 제공한다. 하네스는 모니터가 2대 미만이거나, Axicultuss·Axicultus·Easislides가 실행 중이거나, 격리 사본이 없거나, 읽은 데이터 폴더가 사본 밖이면 본창을 만들지 않는다. 실행 전후로 실제 설정 폴더와 데이터 폴더의 파일 목록을 비교해 바뀌었는지 출력한다. 하네스는 다른 프로세스를 끝내지 않는다.

#### Scenario: 실행 중인 앱이 있을 때

- **GIVEN** Axicultuss가 실행 중이다
- **WHEN** 하네스를 실행한다
- **THEN** 하네스는 아무것도 띄우지 않고 이유를 출력하며, 실행 중인 앱은 그대로다

#### Scenario: 실제 데이터 보호

- **GIVEN** 격리 사본이 있다
- **WHEN** 하네스가 `captiontab` 단계를 끝낸다
- **THEN** 실제 설정 폴더와 데이터 폴더는 unchanged로 출력된다

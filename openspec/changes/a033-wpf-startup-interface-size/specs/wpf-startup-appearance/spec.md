## ADDED Requirements

### Requirement: WPF 시작 크기
운영 콘솔은 저장된 인터페이스 크기로 바로 열려야 한다(SHALL). 크기 기본값은 표준이다.

#### Scenario: 새 설정 또는 이전 버전의 미완료 설정
- **WHEN** 저장한 크기가 없거나 표준이고 시작 설정 완료 값이 없거나 false인 사용자가 WPF를 실행한다.
- **THEN** 콘솔을 표준 크기로 표시하고 크기 선택을 요구하지 않는다.

#### Scenario: 사용자가 크기를 변경하고 다시 실행
- **WHEN** 설정에서 큰 글씨 또는 시니어를 선택하고 WPF를 다시 실행한다.
- **THEN** 시작 설정 완료 여부에 관계없이 메인 창을 처음 표시할 때부터 저장한 크기를 적용한다.

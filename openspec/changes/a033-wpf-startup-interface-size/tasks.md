## 구현 및 검증

- [x] 1. 새 설정과 기존 설정에서 크기 선택 없이 시작하는 회귀 조건을 추가한다.
- [x] 2. 자동으로 열리는 크기 선택 경로를 제거하고 메인 창 생성 전에 사용자 크기를 적용한다.
- [x] 3. WPF 테스트와 격리된 앱 실행으로 표준 및 저장한 크기를 확인한다.

## 검증 결과

- 격리한 새 프로필과 세 가지 이전 프로필로 운영 콘솔을 열었다. 첫 표시 시 새 프로필과 이전 표준은 본문 14.0 DIP, 큰 글씨는 16.8 DIP, 시니어는 19.6 DIP였다. 네 경우 모두 크기 선택 창이 없었고 메인 창이 입력을 받을 수 있었다.
- 기존 시작 경로에서 회귀 테스트 실패를 확인한 뒤 변경을 적용했다.

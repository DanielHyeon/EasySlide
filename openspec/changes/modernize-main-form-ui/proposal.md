# Change: 메인 화면(FrmMain) 표현 현대화

## Why

지금 메인 화면은 배치와 사용 흐름이 좋지만 표현에 문제가 있다.

- 미리보기 단과 송출 단이 똑같이 보인다. 두 단 모두 같은 썸네일에 같은 빨간 선택 테두리를 쓴다.
- 검은 화면, 글자 숨김, 쇼 시작 버튼이 작은 아이콘 3개로 붙어 있어 잘못 누르기 쉽고, 켜진 상태를 알아보기 어렵다.
- 송출 단에서 다음에 나갈 슬라이드를 알 수 없다.
- 예배 순서에서 구분 항목(`■영광송` 등)과 일반 항목이 섞여 보이고, 종류는 작은 아이콘으로만 구분된다.
- 아래쪽 큰 화면의 양옆 회색 여백이 비어 있다.
- 썸네일은 항상 한 줄 3개, 4:3으로 고정돼 있다 (`FrmMain.Layout.cs`).

목표는 **배치와 조작 방법은 그대로 두고 표현만 바꾸는 것**이다. 기준 시안은 "시안 E · 기존 구조 현대화"다.

## What Changes

작업 묶음 10개로 나눈다. 한 번에 하나씩 진행한다 (순서는 목록 아래).

1. **미리보기/송출 색 구분**: 머리줄 바탕색, 썸네일과 가사 목록의 선택 테두리 색을 미리보기는 파랑, 송출은 주황으로 나눈다. 색과 적용 코드를 한곳에 모으고, 이전 모양으로 되돌리는 설정을 둔다.
2. **송출 상태 표시와 실수 방지**: 상태 글자를 항상 보여 주고, 쇼 버튼을 떨어뜨리고, 다음 슬라이드를 표시한다.
3. **버튼 설명과 찾기 칸**: 아이콘 버튼 설명에 단축키를 넣고 찾기 칸을 넓힌다.
4. **예배 순서 목록 표현**: 구분 줄 강조, 종류 꼬리표, 송출 중/미리보기 표시, 긴 제목 말줄임.
5. **찬양 목록 표현**: 제목과 번호 분리, 폴더 안 바로 찾기.
6. **아래 화면 영역**: 다음 슬라이드 미리보기와 정보 칸.
7. **썸네일 배치 계산 정리**: 열 수 자동 조절, 슬라이드 비율 유지.
8. **툴바 정리**: 아이콘과 글자 함께 표시, 묶음 구분.
9. **아이콘 교체** (2026-11-17 추가): 크기와 굵기가 제각각인 그림을 한 벌의 아이콘으로 바꾼다. 화면 배율에 맞춰 또렷하게 그린다.
10. **글꼴과 표면 정리** (2026-11-17 추가): 남은 옛 글꼴, 입체 테두리, 그라데이션 툴바, 제각각인 바탕색을 정리한다.

진행 순서는 1~4(완료) 뒤에 9와 8, 10, 5, 6, 7이다.

## Out of Scope

- 탭 위치 변경, 단 배치 변경, 메뉴 구조 변경. 익숙한 위치를 유지한다.
- 화면 문구의 한글화. 지금의 영문 문구를 그대로 둔다. 필요하면 별도 변경으로 제안한다.
- WPF, WinUI 3 전환과 OfficeBridge 분리.
- 송출 창(`FrmLaunchShow`)과 대화상자들의 모양.

## Impact

- 영향 받는 사양: `main-form-ui` (새로 추가)
- 영향 받는 코드: `Easislides/Easislides/FrmMain.*.cs`, `Easislides/Easislides/ImageCanvas.cs`, `Easislides/Global/gfColorsFonts.cs` 또는 새 partial 파일
- 사용자 영향: 화면 색과 표시가 달라진다. 조작 방법과 단축키는 바뀌지 않는다.
- 되돌리기: 설정 하나로 이전 모양으로 돌아갈 수 있어야 한다 (작업 1에서 만든다).

# main-form-ui

## ADDED Requirements

### Requirement: 색 팔레트 단일 정의

메인 화면의 새 모양에 쓰는 색은 한 클래스에 상수로 정의돼야 한다(SHALL). 다른 파일은 이 상수를 참조하고 색 값을 직접 쓰지 않는다.

#### Scenario: 팔레트 값 변경

- **WHEN** 팔레트의 LiveAccent 값을 다른 색으로 바꾸고 빌드한다
- **THEN** 송출 단의 선택 테두리와 켜진 송출 버튼의 색이 모두 그 색으로 바뀐다

### Requirement: 이전 모양으로 되돌리기

새 모양을 끄는 설정이 있어야 한다(SHALL). 기본값은 새 모양 사용이다. 설정을 끄면 이 변경이 적용한 색, 테두리, 표시가 적용되지 않는다.

#### Scenario: 설정을 끄고 실행

- **WHEN** 되돌리기 설정을 끄고 앱을 실행한다
- **THEN** 메인 화면이 변경 전과 같은 모양으로 보인다

#### Scenario: 설정이 없을 때

- **WHEN** 설정 값이 저장돼 있지 않은 상태로 앱을 실행한다
- **THEN** 새 모양이 적용된다

### Requirement: 미리보기와 송출의 색 구분

미리보기 단과 송출 단은 서로 다른 색으로 구분돼야 한다(SHALL). 미리보기는 파랑, 송출은 주황을 쓴다.

#### Scenario: 머리줄 바탕

- **WHEN** 메인 화면을 연다
- **THEN** 미리보기 단의 머리줄 바탕은 PreviewTint이고 송출 단의 머리줄 바탕은 LiveTint다
- **AND** 머리줄의 제목 글자는 그 바탕 위에서 읽을 수 있다

#### Scenario: PPT 썸네일 선택 테두리

- **WHEN** PPT 항목을 미리보기에 올리고 송출로 복사한다
- **THEN** 미리보기 단에서 선택된 썸네일의 테두리는 PreviewAccent다
- **AND** 송출 단에서 송출 중인 썸네일의 테두리는 LiveAccent다

#### Scenario: 가사 목록 선택 표시

- **WHEN** 가사 항목을 미리보기에 올리고 송출로 복사한다
- **THEN** 미리보기 단에서 선택된 슬라이드의 표시는 PreviewAccent 계열이다
- **AND** 송출 단에서 송출 중인 슬라이드의 표시는 LiveAccent 계열이다

#### Scenario: 사용자가 선택 색을 바꾼 경우

- **WHEN** 옵션 창에서 "Selected Colour" 또는 "Selected Back"을 기본값이 아닌 색으로 바꾼다
- **THEN** 두 단의 가사 목록에서 선택된 슬라이드는 사용자가 고른 색으로 표시된다
- **AND** 앱을 다시 시작하지 않아도 반영된다
- **AND** 머리줄 바탕색과 썸네일 테두리의 구분은 그대로 유지된다

### Requirement: 고대비 테마 존중

Windows 고대비 테마가 켜져 있으면 새 모양을 적용하지 않아야 한다(SHALL NOT apply).

#### Scenario: 고대비 테마에서 실행

- **WHEN** Windows 고대비 테마를 켠 상태로 앱을 실행한다
- **THEN** 메인 화면이 되돌리기 설정을 끈 것과 같은 모양으로 보인다

### Requirement: 기존 조작 유지

이 변경은 클릭, 더블클릭, 끌어 놓기, 키 입력의 동작을 바꾸지 않아야 한다(SHALL NOT change).

#### Scenario: 슬라이드 선택

- **WHEN** 미리보기 단이나 송출 단에서 썸네일 또는 가사 줄을 클릭한다
- **THEN** 변경 전과 같은 슬라이드로 이동한다

#### Scenario: 송출 단축키

- **WHEN** F3, F5, F7, F8, F9, F12와 방향키를 누른다
- **THEN** 변경 전과 같은 동작이 일어난다

### Requirement: 송출 상태 글자 표시

송출 단은 쇼 진행 여부, 글자 표시 여부, 검은 화면 여부를 항상 글자로 보여 줘야 한다(SHALL). 색만으로 상태를 나타내지 않는다.

#### Scenario: 검은 화면을 켠다

- **WHEN** 검은 화면을 켠다
- **THEN** 상태 줄에 검은 화면이 켜졌다는 글자가 보인다
- **AND** 검은 화면 버튼이 켜진 모양으로 바뀐다

#### Scenario: 아무것도 켜지 않은 상태

- **WHEN** 쇼가 꺼져 있고 검은 화면과 글자 숨김도 꺼져 있다
- **THEN** 상태 줄은 사라지지 않고 꺼진 상태임을 글자로 보여 준다

### Requirement: 송출되지 않는 상태의 구분

쇼가 꺼져 있거나 검은 화면 또는 간격 항목이 나가는 동안에는, 송출 단의 현재 슬라이드 표시가 실제로 화면에 나가는 중일 때와 달라야 한다(SHALL). 주황 채움은 실제로 나가는 슬라이드에만 쓴다.

#### Scenario: 쇼가 꺼진 상태

- **WHEN** 쇼를 시작하지 않고 미리보기를 송출 단으로 복사한다
- **THEN** 송출 단의 현재 슬라이드는 주황으로 채워지지 않고, 나가지 않는 상태임을 알 수 있게 표시된다

#### Scenario: 검은 화면

- **WHEN** 쇼 진행 중에 검은 화면을 켠다
- **THEN** 송출 단의 현재 슬라이드 표시가 나가지 않는 상태의 표시로 바뀐다

### Requirement: 쇼 버튼 분리

쇼 시작/종료 버튼은 글자 숨김, 검은 화면 버튼과 떨어져 있어야 한다(SHALL). 간격은 다른 버튼 사이 간격보다 눈에 띄게 넓다.

#### Scenario: 버튼 배치

- **WHEN** 송출 단의 머리줄을 본다
- **THEN** 쇼 버튼과 옆 버튼 사이의 간격이 글자 숨김과 검은 화면 버튼 사이의 간격보다 넓다

### Requirement: 다음 슬라이드 표시

송출 단의 PPT 썸네일은 다음에 나갈 슬라이드를 표시해야 한다(SHALL). 송출 중인 슬라이드와는 선 모양으로 구분하고, 다음 슬라이드의 선은 현재 슬라이드의 선보다 가늘어야 한다(SHALL). 가사 목록에는 이 표시를 넣지 않는다.

#### Scenario: 송출 중에 다음 슬라이드가 있다

- **WHEN** 슬라이드가 여러 장인 PPT 항목의 첫 장을 송출한다
- **THEN** 송출 단에서 첫 장은 LiveAccent 실선 테두리, 둘째 장은 NextSlide 점선 테두리다

#### Scenario: 현재와 다음이 어긋나지 않는다

- **WHEN** 어떤 방법으로든 슬라이드를 넘긴다
- **THEN** 점선 테두리는 실선 테두리가 붙은 썸네일의 바로 다음 썸네일에만 있다

#### Scenario: 마지막 슬라이드

- **WHEN** 항목의 마지막 장을 송출한다
- **THEN** 점선 테두리가 붙은 슬라이드가 없다

### Requirement: 버튼 설명에 단축키 표시

미리보기 단과 송출 단의 아이콘 버튼 설명에는 그 버튼의 단축키가 함께 표시돼야 한다(SHALL). 메인 화면 어디에 포커스가 있든 버튼과 같은 동작을 하는 키만 표시한다(SHALL). 그런 키가 없는 버튼은 설명만 표시한다.

#### Scenario: 검은 화면 버튼에 마우스를 올린다

- **GIVEN** 전역 키 옵션이 기본값이다
- **WHEN** 검은 화면 버튼에 마우스를 올린다
- **THEN** 설명에 버튼 이름과 F9가 함께 보인다

#### Scenario: 포커스가 있어야 먹는 키

- **WHEN** 슬라이드 넘기기 버튼에 마우스를 올린다
- **THEN** 설명에 단축키가 붙지 않는다 (방향키는 그 단에 포커스가 있을 때만 먹는다)

#### Scenario: 옵션에서 키 설정을 바꾼다

- **WHEN** 옵션에서 전역 키 설정을 바꾸고 저장한다
- **THEN** 앱을 다시 시작하지 않아도 버튼 설명의 키가 바뀐 설정을 따른다

### Requirement: 넓은 찾기 칸

툴바의 찾기 칸은 창 너비에 여유가 있으면 지금보다 넓어야 한다(SHALL). 창이 좁아지면 다른 툴바 버튼을 가리지 않고 줄어든다.

#### Scenario: 넓은 창

- **GIVEN** 화면 배율이 150% 이하다
- **WHEN** 창 너비가 1600픽셀 이상이다
- **THEN** 찾기 칸의 너비가 300픽셀 이상이다

#### Scenario: 목록이 펼쳐져 있다

- **WHEN** 찾기 칸의 목록을 펼친 채로 창이 넓어진다
- **THEN** 목록이 닫히지 않고, 목록을 닫은 뒤에 칸이 넓어진다

#### Scenario: 목록이 펼쳐진 채로 창이 좁아진다

- **WHEN** 찾기 칸의 목록을 펼친 채로 창이 좁아져 칸을 줄여야 한다
- **THEN** 칸이 바로 줄고 목록은 닫힌다
- **AND** 툴바의 어떤 항목도 넘침 메뉴로 밀려나지 않는다

### Requirement: 예배 순서 목록 표현

예배 순서 목록은 구분 항목, 항목 종류, 송출 중인 항목, 미리보기 중인 항목을 구분해 보여 줘야 한다(SHALL). 목록의 데이터와 조작은 바꾸지 않는다.

#### Scenario: 구분 항목

- **WHEN** 제목이 `■` 또는 `★`로 시작하는 항목이 목록에 있다
- **THEN** 그 줄은 굵은 글씨이고, 바탕색과 윗선으로 다른 줄과 구분된다
- **AND** 줄 높이는 다른 줄과 같다

#### Scenario: 송출 중인 항목

- **WHEN** 예배 순서 목록에서 올린 항목이 쇼에서 실제로 나가고 있다
- **THEN** 그 줄은 LiveTint 바탕이고 `LIVE` 글자가 붙는다

#### Scenario: 송출 단에 있지만 나가지 않는 항목

- **WHEN** 예배 순서 목록에서 올린 항목이 송출 단에 있고, 쇼가 꺼져 있거나 검은 화면이다
- **THEN** 그 줄에 `LIVE`가 아닌 `OUT` 글자가 붙고 바탕은 칠하지 않는다

#### Scenario: 미리보기 중인 항목

- **WHEN** 예배 순서 목록의 항목을 미리보기 단에 올린다
- **THEN** 그 줄에 파란 표시 띠와 `PREVIEW` 글자가 붙는다
- **AND** 그 줄이 선택돼 있지 않으면 바탕이 PreviewTint다 (선택된 줄은 선택 색을 쓴다)
- **AND** 이전에 미리보기 중이던 줄의 표시는 바로 사라진다

#### Scenario: 틀린 줄에 표시하지 않는다

- **WHEN** 자료 목록에서 바로 올린 항목이 송출 단에 있거나, 목록을 고쳐서 위치가 맞지 않게 됐다
- **THEN** 예배 순서 목록의 어느 줄에도 송출 표시가 붙지 않는다

#### Scenario: 좁은 목록

- **WHEN** 목록이 좁다
- **THEN** 항목 종류 글자는 생략되고 제목이 그 자리를 쓴다. `LIVE`, `OUT`, `PREVIEW`는 생략되지 않는다

#### Scenario: 긴 제목

- **WHEN** 제목이 줄 너비보다 길다
- **THEN** 제목은 말줄임표로 끝난다

#### Scenario: 끌어서 순서 바꾸기

- **WHEN** 항목을 끌어 다른 위치에 놓는다
- **THEN** 변경 전과 같이 순서가 바뀌고 저장된다

### Requirement: 찬양 목록 표현

찬양 목록은 제목과 번호를 나눠 보여 줘야 하고(SHALL), 지금 폴더 안에서 바로 찾는 입력 칸을 제공해야 한다(SHALL).

#### Scenario: 폴더 안 찾기

- **WHEN** 입력 칸에 글자를 넣는다
- **THEN** 목록이 그 글자가 제목에 들어 있는 곡만 보여 준다
- **AND** 입력 칸을 비우면 폴더의 모든 곡이 다시 보인다

### Requirement: 아래 화면 영역의 정보

송출 단의 큰 화면 옆에는 다음 슬라이드 미리보기, 슬라이드 위치, 다음 항목 이름이 표시돼야 한다(SHALL). 미리보기 단의 큰 화면 옆에는 슬라이드 위치와 항목 정보가 표시돼야 한다(SHALL). 슬라이드 노트는 기본으로 접혀 있다.

#### Scenario: 송출 중

- **WHEN** 8장짜리 항목의 3번째 장을 송출한다
- **THEN** 큰 화면 옆에 4번째 장의 미리보기와 "3 / 8"에 해당하는 위치가 보인다

#### Scenario: 슬라이드 노트

- **WHEN** 미리보기 단을 처음 본다
- **THEN** 슬라이드 노트 내용은 보이지 않고, 펼치는 조작을 해야 보인다

### Requirement: 썸네일 배치

PPT 썸네일은 단 너비에 따라 한 줄의 개수가 정해져야 하고(SHALL), 슬라이드의 실제 가로세로 비율로 표시돼야 한다(SHALL).

#### Scenario: 단을 넓힌다

- **WHEN** 구분선을 끌어 미리보기 단을 넓힌다
- **THEN** 한 줄의 썸네일 수가 늘어난다

#### Scenario: 16:9 슬라이드

- **WHEN** 16:9 PPT를 미리보기에 올린다
- **THEN** 썸네일 상자가 16:9이고 위아래에 빈 띠가 없다

### Requirement: 툴바 표시

툴바 버튼은 아이콘과 짧은 글자를 함께 보여 줘야 한다(SHALL). 삭제 버튼은 다른 편집 버튼과 떨어져 있어야 한다(SHALL).

#### Scenario: 처음 보는 사용자

- **WHEN** 툴바를 본다
- **THEN** 각 버튼의 기능을 마우스를 올리지 않고도 글자로 알 수 있다

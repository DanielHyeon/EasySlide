# 제안: WPF 설정 패널 입력/체크박스 잘림 수정

## 배경

설정/서식 패널의 텍스트 박스와 체크박스 내용이 아래쪽 또는 옆으로 잘려 보인다는 문제가 계속 보고되었다.

## 문제

현재 설정 패널 텍스트 박스는 높이와 세로 패딩이 작아 폰트 렌더링, DPI, 포커스 border 두께 변화에서 글자 하단이 잘릴 수 있다. `Use Individual Settings` 체크박스는 별도 설정 패널용 스타일이 없어 기본 템플릿/높이에 의존한다.

## 목표

- 설정 패널 텍스트 박스의 글자 하단이 잘리지 않도록 최소 높이와 세로 패딩을 늘린다.
- 체크박스도 설정 패널용 최소 높이와 세로 정렬을 명시한다.
- XAML 구조 테스트로 회귀를 막는다.
- 구현 후 실제 앱 캡처를 시도하고 결과를 기록한다.

## 비목표

- 설정 패널 레이아웃 전체를 재설계하지 않는다.
- 송출/미리보기 로직은 변경하지 않는다.
- 색상 테마 또는 폰트 시스템을 변경하지 않는다.

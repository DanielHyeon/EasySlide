## Context

직접 입력과 PPT 따라가기는 하나의 CaptionSession을 공유한다. Windows IME는 텍스트가 확정되기 전에도 입력 이벤트를 발생시킬 수 있다. 전역 UI 예외 핸들러는 현재 모든 오류를 처리 완료로 표시한다.

## Goals / Non-Goals

직접 입력 탭에서 편집, 실시간 반영 및 명시적 송출의 경계를 테스트할 수 있게 하고 콘솔과 앱의 예외 기록을 운영 빌드에서 읽을 수 있게 한다. 기존 PPT 따라가기, OBS, 카메라 및 복구 파일 형식을 유지한다.

## Decisions

- 창이 키·포커스·IME 이벤트를 받아 ViewModel로 전달한다. ViewModel은 초안과 실시간 선택을 보관하고 기존 CaptionSession에 송출과 이력 기록을 위임한다. 초안 변경과 명시적 송출은 기존 디바운스 저장을 요청한다.
- PPT를 읽는 동안 기존 세션을 유지한다. 예상한 파일·변환 실패를 비모달 상태 메시지와 사용자별 오류 파일에 기록한다.
- 예기치 않은 Dispatcher 예외는 기록한 뒤 런타임에 전달한다. 도메인 종료와 관측되지 않은 작업 예외도 같은 출력 위치를 사용한다.

## Risks / Trade-offs

IME 확정과 WPF 바인딩의 실행 순서는 실제 창과 Dispatcher를 사용하는 테스트로 확인한다. 오류 기록 장치의 실패가 원래의 예외 처리를 방해하지 않도록 한다.

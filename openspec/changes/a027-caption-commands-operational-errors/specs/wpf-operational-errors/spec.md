## Purpose

예배 운영자가 자막 PPT를 열다가 실패했을 때 기존 송출을 유지하고 원인을 찾을 수 있게 한다. 운영 빌드에서 예외의 발생 경로와 세부 정보를 사용자별 파일에 남긴다.

## ADDED Requirements

### Requirement: 자막 PPT 준비 실패 복구

시스템 SHALL 자막 PPT 준비 중 발생한 예상 가능한 오류를 콘솔에 알리고 기존 송출과 선택을 유지한다.

#### Scenario: 손상되거나 사라진 PPT

- **WHEN** 콘솔에서 읽을 수 없는 PPT를 준비한다
- **THEN** 콘솔 상태에 오류를 표시하고 오류 기록에 작업명과 예외를 남기며 기존 송출 문구와 준비된 PPT를 유지한다.

### Requirement: 운영 예외 기록과 종료 정책

시스템 SHALL Release에서도 UI, 도메인, 관측되지 않은 작업 예외를 사용자별 오류 파일에 기록하고 미처리 UI 오류는 런타임의 종료 정책에 전달한다.

#### Scenario: 예상하지 못한 UI 오류

- **WHEN** Dispatcher에 처리되지 않은 예외가 도달한다
- **THEN** 예외를 기록하고 계속 실행한다는 알림이나 자동 복구 없이 WPF의 기본 예외 처리를 따른다.

#### Scenario: 로그 디렉터리 접근 실패

- **WHEN** 파일 시스템이 예외 기록을 거부한다
- **THEN** 원래 작업의 오류 안내 또는 전역 종료 판단을 그대로 수행한다.

## Context

CodeGraph의 로컬 인덱스에서 MainWindow, CameraOwnership, MediaPlaybackService, ObsConnection 심볼을 찾지 못해 실제 호출 경로를 대조했다. MainWindow의 ClassicOutputTopStrip이 운영자 도구를 표시한다. MediaPlaybackService는 지연 부착 브리지를 통해 관객 출력의 WpfMediaElementPlaybackBackend에 연결된다. OBS 연결당 수신 루프는 하나다.

## Goals / Non-Goals

운영자가 송출 패널을 떠나지 않고 입력 장치를 선택하고 결과를 확인한다. 옵션의 기본 장치 값과 운영 레지스트리를 쓰지 않는다.

## Decisions

- 로컬 카메라를 안정적인 장치 경로로 별도 그래프에서 준비하고 첫 프레임이 도착하면 같은 그래프를 송출 표면에 붙인다. 대기 중 중지·소스 교체·출력 창 종료는 전환을 취소한다.
- OBS에서는 운영자가 변경할 입력 소스를 식별한 뒤 OBS가 제공한 장치 값을 사용한다. 장치 변경은 기존 세션에서 해당 소스에만 적용하고 설정을 다시 읽어 확인한다.
- 장치 목록은 아이콘을 누를 때마다 갱신한다. 방송 화면과 옵션의 점검은 독립적으로 유지한다.

- 마이크의 현장 경로는 공유 모드 WASAPI 작업 스레드에서 선택한 입력과 스피커를 연결한다. 양쪽 엔드포인트 및 첫 입력 패킷 준비 후 전환한다. 현장 경로는 메뉴에서 끄거나 송출·앱 종료 시 중단한다.
- OBS 방송에서 현장으로 바꾸면 앱에서 선택했던 OBS 입력만 음소거한다. 같은 입력으로 돌아오면 전환 과정에서 적용한 음소거만 푼다. OBS가 끊겨 이전 음소거를 확인할 수 없는 경우 운영자에게 알린다. 장치 선택 전에 소스의 프로그램 활성 상태를 표시한다.

## Risks / Trade-offs

카메라 드라이버 점유·분리 때문에 새 신호가 없을 수 있다. OBS가 장치 설정을 수락했는지와 실물 장치 신호 수신은 구분해 표시한다.

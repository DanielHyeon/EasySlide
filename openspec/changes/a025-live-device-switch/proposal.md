# 송출 패널의 입력 장치 전환

## Why

예배 중 운영자가 송출 패널에서 카메라와 마이크를 직접 교체할 수 있어야 한다. 옵션의 장치 점검은 독립적으로 실행된다.

## What Changes

- WPF 운영 화면의 Output 머리줄에 카메라·마이크 선택 아이콘을 추가한다.
- 로컬 카메라는 첫 프레임이 도착한 장치를 실제 송출에 연결한다. OBS가 담당하는 입력은 해당 OBS 소스의 장치 설정을 바꾼다.

- 마이크 아이콘에는 OBS 방송과 현장 스피커 경로를 제공한다. 현장은 Windows 출력 장치와 마이크를 선택해 실시간 음성을 전달한다.

## Capabilities

### New Capabilities

- `live-device-switch` 송출 중 영상·오디오 입력 전환

## Impact

운영자 메인 창, WPF 카메라 재생 경로와 OBS WebSocket 입력 제어가 대상이다. 관객 화면에는 조작 UI를 표시하지 않는다.

## 검증 결과

- Release 빌드와 격리된 전체 회귀 테스트가 통과했다. WPF 2,601개, 분석기 20개, 기존 앱 235개다.
- 실제 운영자 창에서 너비 1,180 및 최소 너비 780으로 두 아이콘의 경계와 클릭 메뉴를 확인했다. 장치 조회와 테스트는 운영 HKCU와 분리했다.
- 로컬 OBS 프로토콜 서버에서 카메라·마이크 장치 식별자 변경, 적용 재조회, 전환 시 음소거 및 복원, 기존 음소거 보존을 검증했다.
- Windows 기본 Realtek USB 스피커에서 공유 모드로 48 kHz 모노 무음 버퍼를 출력했다. 이 PC의 카메라와 활성 마이크 수는 0개였다. 실물 카메라 전환 및 마이크 음성의 종단 간 송출은 미검증이다.

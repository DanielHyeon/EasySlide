## Purpose

예배 운영자가 운영자 송출 화면에서 카메라와 마이크 입력을 선택하고, 현재 사용 중인 입력과 실제 전환 결과를 확인할 수 있도록 한다.

## ADDED Requirements

### Requirement: 송출 패널의 장치 메뉴
시스템 SHALL 운영자 Output 머리줄에 카메라 및 마이크 아이콘을 표시하고 메뉴를 열면 선택 가능한 장치와 현재 선택을 표시한다.

#### Scenario: 장치 목록 확인
- **WHEN** 운영자가 아이콘을 누른다
- **THEN** 출력 상태는 그대로 유지되며 사용 가능한 장치 또는 연결 안내가 표시된다.

### Requirement: 로컬 송출 카메라 변경
시스템 SHALL 선택한 로컬 카메라의 첫 프레임을 수신한 뒤 해당 카메라를 송출한다.

#### Scenario: 송출 중 장치 분리 또는 전환 취소
- **WHEN** 선택한 장치가 응답하지 않거나 대기 중에 송출이 종료된다
- **THEN** 준비한 카메라를 해제하고 뒤늦게 도착한 장치로 송출을 시작하지 않는다.

### Requirement: OBS 송출 입력 장치 변경
시스템 SHALL OBS 카메라 모드의 영상 캡처 또는 OBS 방송용 마이크 입력에서 선택한 장치만 변경한다.

#### Scenario: 운영자가 대상 소스와 장치를 선택
- **WHEN** 유효한 OBS 제어 연결에서 대상 소스의 새 장치를 선택한다
- **THEN** OBS에 장치 식별자를 적용하고 재조회 결과를 표시한다. 같은 소스의 장치 변경 시 씬, 음소거, 볼륨은 유지한다.

### Requirement: 마이크 송출 목적지 전환
시스템 SHALL 마이크 메뉴에서 OBS 방송 또는 Windows 현장 스피커를 선택할 수 있게 한다.

#### Scenario: 현장 스피커 선택
- **WHEN** 운영자가 현장 스피커와 마이크를 선택한다
- **THEN** 두 장치를 준비하고 입력을 받은 뒤 스피커로 음성을 전달한다. 새 장치 준비 실패 시 기존 경로를 유지한다.

#### Scenario: 방송과 현장을 오가는 경우
- **WHEN** 운영자가 앱에서 선택한 OBS 입력을 현장 스피커로 전환하거나 해당 OBS 입력으로 되돌아간다
- **THEN** 현장 경로의 시작·정지와 해당 OBS 입력의 음소거를 조율하고 이전부터 음소거된 입력은 그 상태를 유지한다. OBS에 접근할 수 없으면 이전 음소거 상태를 확인하도록 알린다.

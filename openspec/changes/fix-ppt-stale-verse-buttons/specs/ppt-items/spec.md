# ppt-items

## ADDED Requirements

### Requirement: PPT 항목의 절 버튼은 그 파일의 노트만 따른다

PPT 항목을 미리보기 단이나 송출 단에 올리면, 절 버튼은 그 파일의 슬라이드 노트에 있는 절 표시와 일치해야 한다(SHALL). 직전에 올렸던 항목의 절 정보가 남으면 안 된다(SHALL NOT). 같은 순서로 올리면 항상 같은 결과가 나와야 한다(SHALL).

#### Scenario: 노트가 없는 PPT

- **GIVEN** 슬라이드 노트가 없는 PPT 항목
- **WHEN** 앱을 막 켠 상태에서 이 항목을 송출 단에 올린다
- **THEN** 절 버튼이 하나도 나오지 않는다

#### Scenario: 절이 있는 가사 항목 뒤에 올린다

- **GIVEN** 1절이 있는 가사 항목이 송출 단에 올라가 있다
- **WHEN** 노트가 없는 PPT 항목을 송출 단에 올린다
- **THEN** 절 버튼이 하나도 나오지 않는다

#### Scenario: 같은 PPT를 다시 올린다

- **GIVEN** 어떤 PPT 항목을 올렸다가 다른 항목을 올렸다
- **WHEN** 처음의 PPT 항목을 같은 단에 다시 올린다
- **THEN** 절 버튼이 처음 올렸을 때와 같다

#### Scenario: 두 단 모두

- **WHEN** 위 순서를 미리보기 단에서 한다
- **THEN** 미리보기 단의 절 버튼도 같은 규칙을 따른다

#### Scenario: 노트에 절 표시가 있는 PPT

- **GIVEN** 슬라이드 노트에 절 표시가 있는 PPT 항목
- **WHEN** 이 항목을 처음 올리거나 다시 올린다
- **THEN** 두 경우 모두 그 절 표시대로 버튼이 나온다

### Requirement: 절 정보 때문에 PowerPoint를 불필요하게 다시 열지 않는다

같은 파일의 절 정보를 이번 실행에서 이미 읽었고 파일이 바뀌지 않았으면, 앱은 파일을 다시 열지 않고 읽어 둔 값을 써야 한다(SHALL). 쇼 진행 중에 송출 단에 올리는 경우처럼 바로 뒤에 다른 경로가 절 정보를 다시 읽는 경우에는 따로 읽지 않는다(SHALL NOT).

#### Scenario: 같은 PPT를 다시 올린다 (읽어 둔 값이 있다)

- **GIVEN** 어떤 PPT 항목을 이번 실행에서 한 번 올렸다
- **WHEN** 그 항목을 같은 단에 다시 올린다
- **THEN** 절 버튼이 맞게 나오고, 절 정보를 읽으려고 파일을 다시 열지 않는다

#### Scenario: 파일이 바뀌었다

- **WHEN** 파일이 수정된 뒤 다시 올린다
- **THEN** 읽어 둔 값을 쓰지 않고 다시 읽는다

#### Scenario: 쇼 진행 중

- **WHEN** 쇼 진행 중에 PPT 항목을 송출 단에 다시 올린다
- **THEN** 쇼를 시작하는 경로가 읽는 절 정보를 그대로 쓰고, 그 전에 파일을 따로 열지 않는다

### Requirement: 절 정보를 읽지 못해도 항목은 올라간다

절 정보를 다시 읽다가 실패하면 절 버튼 없이 항목을 표시해야 한다(SHALL). 예외가 밖으로 나가면 안 되고(SHALL NOT), 열었던 프레젠테이션은 닫아야 한다(SHALL).

#### Scenario: 파일을 열 수 없다

- **WHEN** 절 정보를 다시 읽으려는데 파일을 열 수 없다
- **THEN** 썸네일은 그대로 나오고 절 버튼은 나오지 않는다

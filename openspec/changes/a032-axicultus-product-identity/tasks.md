## 검증 결과

- Release 회귀 테스트 2,945개를 통과했다. WPF 2,642개, WinForms·공유 코드 283개, 분석기 20개다.
- 두 앱을 같은 배포 폴더에 게시하고 EXE 제품명, 파일 설명과 DLL의 CLR 어셈블리 이름을 확인했다. WPF 메인 창은 Axicultus, WinForms 정보 창은 About Axicultuss를 표시했다. 두 창의 Windows 작은 아이콘 20px와 큰 아이콘 40px를 원본과 대조했다.
- 격리 배포에서 WPF의 `--legacy-ui`가 같은 폴더의 Axicultuss.exe 검증 프로세스를 실행한 뒤 종료하는 것을 확인했다.
- 671개 C# 파일의 식별자를 Roslyn으로 검사했다. 옛 제품명이 들어간 식별자는 0개였다. 기존 파일 형식, 레지스트리 경로, 라이선스에 필요한 문자열은 용도에 맞게 보존했다.
- 사용자의 승인으로 운영 레지스트리 설정값 168개와 WPF 프로필 파일 3개를 새 위치에 복사했다. 문자열 확장 전 값, 레지스트리 자료형, 하위 키와 파일별 SHA-256이 일치했다. 재실행 후에도 원본 및 복사본을 다시 대조했다.

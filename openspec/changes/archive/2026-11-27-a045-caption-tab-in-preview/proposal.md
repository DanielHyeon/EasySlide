# 카메라 자막을 본창 미리보기 칸의 탭으로

## Why

사용자 보고: 카메라 하단 자막 운영 창이 별도 창으로 떠서 쓰기 불편하다. 예배 중에 본창과 운영 창을 오가야 하고, 두 창이 화면과 키보드를 나눠 쓴다(어느 창이 앞에 있느냐에 따라 Space가 "다음"이 되기도 하고 "자막 켜기/끄기"가 되기도 한다). 운영 창을 최대화하면 본창이 가려져, a041에서 운영 창 안에 예배 순서를 다시 만들어 넣어야 했다.

사용자 흐름: 예배 중 카메라·OBS 자막 운영(본창 송출과 함께).

a037의 비목표 "주 창에 붙이지 않는다(별도 창 유지)"를 사용자 요청으로 뒤집는다.

## What Changes

- 운영 창(별도 창)을 없애고, 본창 미리보기 칸 맨 위에 `[미리보기] [● 자막]` 탭 줄을 둔다. 탭 줄은 메뉴 "출력 › 카메라 하단 자막"(또는 F2)으로 처음 열 때 나타나고, 그 전에는 본창이 지금과 같다.
- 탭 줄 오른쪽에 자막 켜기/끄기 스위치를 둔다. 두 탭 어디서나 보이며 상태(숨김·나가는 중·화면 꺼짐 대기)를 색과 글자로 보여 준다. "자막" 탭 이름 앞의 점도 같은 색이다.
- "자막" 탭은 미리보기 칸 폭의 한 줄 배치다: 원본(화면 따라가기 / 직접 입력)·OBS 상태·설정 → 표시 방식과 단계 목록(또는 직접 입력 칸) → 안내 한 줄 → 이전·다음·위치·싱크 → 카메라 화면(16:9) → 자막 모양·내보낼 곳.
- 탭을 바꿔도 자막은 멈추지 않는다(따라가기·송출은 숨은 탭에서도 계속된다).
- 키: F6은 본창 어디서나 자막 켜기/끄기, F2는 미리보기/자막 탭 전환(자막을 아직 열지 않았으면 연다). 자막 탭을 누른 동안에는 지금 운영 창의 키(Space 켜기/끄기, Esc 숨김, ←→↑↓ 단계, 1~4 표시 방식)를 그대로 쓰고, 기능 키와 Ctrl·Alt 단축키는 본창으로 간다. 자막 탭 밖에서는 Space가 지금처럼 "다음"이다.
- 운영 창 안의 예배 순서 목록(a041)을 없앤다. 본창 예배 순서가 바로 옆에 있다.
- 운영 창의 위치·크기 기억(`caption-window.json`)을 없앤다. 설정 창(OBS·카메라·씬·복구·PPT 세부 조정)은 지금처럼 별도 창이다.

## Non-goals

- 자막 송출 규칙(숨김으로 시작, 싱크, 줄 수, 악보 크기, OBS 페이지, 화면 꺼짐 대기)은 바꾸지 않는다.
- 탭 줄을 껐다 켜는 메뉴, 다음 실행 때 자막 탭을 저절로 여는 설정, 자막 칸을 다시 별도 창으로 떼어 내는 기능.
- 싱크가 켜져 있을 때 본창의 다음/이전(Space·리모컨)이 악보 줄부터 넘기는 것.
- 회중 송출 화면, OBS 프로토콜, DB는 바뀌지 않는다. 송출 칸(Output) 열과 왼쪽 열은 바뀌지 않는다.

## Impact

- 영향: `Captions/CaptionConsole.xaml(.cs)`, `CaptionConsole.Operator.cs`(창 → 본창 안의 칸), 새 `Captions/CaptionTabStrip.xaml(.cs)`, `CaptionWindowPlacement.cs`(설정 창 배치만 남김), `MainWindow.xaml(.cs)`(탭 줄·키), `Input/CommandCatalog.cs`·`Shell/MainCommandIds.cs`(F6·F2 명령), 문구(`CaptionConsole`, `MainWindow`, `CommandCatalog`, `MenuText`).
- 미리보기 칸만 바뀐다. 라이브 송출·송출 칸·Office·DB·모니터 배치는 바뀌지 않는다.
- 테스트: 운영 창 테스트(창 위치·예배 순서 목록 테스트 삭제, 나머지는 본창 칸으로), 하네스 `pptcaption`·`consolelist` 단계.
- 저장: 프로필의 `caption-window.json`은 더 이상 읽고 쓰지 않는다(있어도 무해). `caption-style.json`은 그대로.

## Capabilities

### Modified Capabilities

- `live-camera-captions`: 운영 창 → 본창 미리보기 칸의 자막 탭, 키보드, 예배 순서 목록 제거.

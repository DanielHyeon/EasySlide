## ADDED Requirements

### Requirement: 본창 미리보기 칸의 자막 탭

시스템 SHALL 카메라 하단 자막 운영을 별도 창이 아닌 본창 미리보기 칸의 "자막" 탭으로 제공한다. 메뉴 "출력 › 카메라 하단 자막"이나 F2로 처음 열면 미리보기 칸 맨 위에 `[미리보기] [자막]` 탭 줄이 나타나고 자막 탭이 골라진다. 그 전에는 본창이 지금과 같다. 탭 줄은 연 뒤 계속 보인다. 탭을 바꾸어도 자막의 따라가기와 송출은 멈추지 않는다. 예배 순서(계획)가 바뀌면 자막은 새 계획으로 다시 시작하고(숨김), 탭 줄과 고른 탭은 그대로다. 미리보기 칸이 낮으면 자막 칸 본문은 잘리지 않고 스크롤된다.

#### Scenario: 처음 열기

- **GIVEN** 본창에 탭 줄이 없다
- **WHEN** 운영자가 메뉴 "출력 › 카메라 하단 자막"을 누른다
- **THEN** 미리보기 칸 맨 위에 탭 줄이 나타나고 자막 탭이 보이며, 자막은 숨김 상태다

#### Scenario: 미리보기 탭에서도 계속 따라가기

- **GIVEN** 자막이 화면 따라가기로 PPT 2장을 내보내는 중이다
- **WHEN** 운영자가 미리보기 탭으로 바꾸고 송출 화면을 3장으로 넘긴다
- **THEN** 자막은 3장이 된다

#### Scenario: 다른 예배 순서를 불러옴

- **GIVEN** 자막 탭이 열려 있다
- **WHEN** 운영자가 다른 예배 순서를 불러온다
- **THEN** 탭 줄과 자막 탭은 그대로 보이고 자막은 숨김으로 다시 시작한다

## MODIFIED Requirements

### Requirement: 송출 상태가 한눈에 보인다

시스템 SHALL 자막 탭 줄 오른쪽에 자막의 송출/숨김 상태를 색과 글자로 보여 주는 전환 스위치를 두고, "자막" 탭 이름 앞에 같은 색의 점을 둔다. 스위치와 점은 미리보기 탭에서도 보인다. 스위치는 세션의 실제 표시 상태를 따르며, 송출을 골랐지만 회중 화면이 꺼져 아무것도 나가지 않는 상태를 따로 보여 준다. 상태 글자는 밝은·어두운 테마 모두에서 읽을 수 있다. 내보낼 곳(카메라, OBS)과 OBS 연결 상태는 자막 탭 안에 있다.

#### Scenario: 숨김으로 시작

- **WHEN** 자막 탭을 처음 연다
- **THEN** 스위치는 숨김 상태를 표시하고 누르면 송출 상태가 된다

#### Scenario: 회중 화면이 꺼진 동안

- **GIVEN** 자막이 송출 중이다
- **WHEN** 회중 화면이 검은 화면(숨김) 상태가 된다
- **THEN** 스위치는 "자막 대기 · 화면 꺼짐"을 보여 주고 자막 탭 미리보기에 내보내지 않는다는 표시가 있다

#### Scenario: 미리보기 탭에서 상태 보기

- **GIVEN** 자막이 송출 중이고 운영자가 미리보기 탭을 보고 있다
- **WHEN** 운영자가 탭 줄을 본다
- **THEN** 스위치는 "자막 나가는 중"이고 "자막" 탭의 점은 송출 색이다

### Requirement: 송출과 같은 비율의 미리보기

시스템 SHALL 자막 탭에 카메라 화면과 같은 16:9 비율의 미리보기를 칸 폭에 맞춰 보여 주고, 자막 영역 폭·줄 수·글자 크기 비율·악보 높이 비율·배경 상자를 카메라 화면과 같은 규칙으로 축소해 그린다. 화면 따라가기에서는 미리보기 위에 단계 목록을 본창 미리보기처럼 여러 줄로 감아 남는 높이에 보여 준다(넘치면 목록 안에서 스크롤, 최소 한 줄). 각 단계는 장(과 줄) 번호와 글(또는 악보 줄 그림)을 보여 주고, 칸에 다 들어가지 않는 글은 툴팁으로 전체를 보여 준다. 자막 모양(줄 수·악보 크기·배경 상자·글자색)과 내보낼 곳은 미리보기 아래에 둔다. 숨김 중에도 미리보기는 송출하면 나갈 자막(직접 입력에서 "입력하는 대로 보내기"를 끈 경우는 마지막으로 보낸 글)을 흐리게 보여 주며, 이때 카메라 화면과 OBS에는 아무것도 나가지 않는다.

#### Scenario: 숨김 중 미리 확인

- **GIVEN** 자막이 숨김 상태이고 운영자가 직접 입력 칸에 글을 썼다
- **WHEN** 운영자가 자막 탭을 본다
- **THEN** 미리보기에 그 글이 흐리게 보이고 "숨김 중" 표시가 있으며 카메라 화면과 OBS에는 자막이 없다

#### Scenario: 낮은 칸

- **GIVEN** 본창이 최소 크기라 자막 칸이 낮다
- **WHEN** 운영자가 자막 탭을 본다
- **THEN** 본문은 스크롤할 수 있고 단계 목록은 최소 한 줄 보이며 조작은 잘리지 않는다

#### Scenario: 악보 두 줄짜리 슬라이드의 첫 줄

- **GIVEN** 악보 모드로 2줄짜리 슬라이드의 1줄을 송출 중이다
- **WHEN** 운영자가 자막 탭을 본다
- **THEN** 미리보기는 1줄이고, 단계 목록에서는 그 슬라이드의 1줄이 강조되며 2줄이 바로 다음 칸이다

### Requirement: 운영 창의 이름과 짜임

시스템 SHALL 자막 탭의 버튼 이름을 하는 일마다 다르게 붙인다. 탭 줄의 스위치는 자막을 켜고 끄며("자막 숨김 · 눌러서 내보내기 (F6)", "자막 나가는 중 · 눌러서 숨김 (F6)", "자막 대기 · 화면 꺼짐 (F6)"), 직접 입력의 버튼은 "자막 보내기 (Enter)"이고, 자막 원본은 "화면 따라가기"와 "직접 입력"이다(이 순서로 놓이고, 자막 탭은 화면 따라가기로 열린다). 한 번에 하나를 고르는 조작(자막 원본, 표시 방식)은 바탕 띠 안에서 고른 것만 테두리 있는 카드로 보이는 선택 막대이고, 명령 버튼과 다르게 보인다. 원본마다 주 동작 하나만 강조색으로 채운다(직접 입력: "자막 보내기", 따라가기: "다음"). 자막 탭은 한 열이다: 원본·OBS 상태·설정, 표시 방식과 단계 목록(또는 직접 입력 칸), 안내 한 줄, 이전·다음·현재 위치(항목 또는 PPT와 장·줄)·싱크, 카메라 미리보기, 자막 모양과 내보낼 곳 순이다. 현재 위치는 이전·다음 옆 한 곳에만 쓴다. 자막 탭이 한 일과 안내는 한 줄(전체 글은 툴팁)에 보이며 그 줄 때문에 다른 조작이 움직이지 않는다. 글자는 본창 본문·버튼 크기(화면 크기 설정을 따른다)이고, 버튼·목록 상자는 32px, 주 동작(자막 보내기, 이전·다음)은 40px이다. 글자색 버튼은 28px이고 지금 쓰는 색에 강조 테두리가 있다.

#### Scenario: 직접 입력의 버튼

- **GIVEN** 자막 탭이 직접 입력이다
- **WHEN** 운영자가 자막 탭을 본다
- **THEN** 입력 칸 아래 강조색 "자막 보내기 (Enter)"가 있고, 이전·다음 줄과 단계 목록은 보이지 않는다

#### Scenario: 쓰는 글자색

- **GIVEN** 자막 글자색이 노랑이다
- **WHEN** 운영자가 자막 모양을 본다
- **THEN** 노랑 버튼에만 강조 테두리가 있다

### Requirement: 키보드 조작

시스템 SHALL 본창 어디서나 F6으로 자막 송출/숨김을 전환하고(자막을 연 뒤, 입력 칸에서도), F2로 미리보기·자막 탭을 바꾼다(자막을 열지 않았으면 연다). 두 키는 설정의 단축키 화면에서 바꿀 수 있다. 포커스가 자막 탭 안에 있으면 Space로 송출/숨김을 전환하고, Esc로 숨기고(쇼를 끝내지 않는다), ←/→ 또는 ↑/↓로 이전/다음 단계로 가고, 1~4로 표시 방식(자동/자막/악보/악보+자막)을 고르며, 이때 Ctrl·Alt 없는 일반 키는 본창 단축키(다음, 절 점프 등)로 가지 않는다. 기능 키와 Ctrl·Alt 단축키는 자막 탭 안에서도 본창 단축키로 동작한다. 포커스가 입력 칸에 있거나 한글 조합 중이면 Space와 1~4는 글자 입력으로 처리한다. 1~4는 화면 따라가기일 때만 동작하고, Esc는 설정 창에서도 자막을 숨긴다. 자막 탭 밖에서는 본창 키가 그대로다(Space는 다음). 자막 칸을 마우스로 누르면 키는 자막 탭으로 가고, 탭 줄을 누르면 고른 탭의 칸으로 간다.

#### Scenario: 자막 탭의 Esc

- **GIVEN** 쇼가 라이브이고 자막이 송출 중이며 운영자가 자막 탭을 눌렀다
- **WHEN** Esc를 누른다
- **THEN** 자막만 숨겨지고 쇼는 계속된다

#### Scenario: 미리보기 탭에서 F6

- **GIVEN** 자막이 숨김이고 운영자가 미리보기 탭의 가사를 보고 있다
- **WHEN** F6을 누른다
- **THEN** 자막이 송출되고 미리보기의 선택은 그대로다

#### Scenario: 자막 탭에서 기능 키

- **GIVEN** 운영자가 자막 탭을 눌렀다
- **WHEN** F9를 누른다
- **THEN** 본창처럼 검은 화면이 켜진다

#### Scenario: 키보드로 고른 체크 상자의 Space

- **GIVEN** 운영자가 Tab으로 "싱크" 체크 상자에 포커스를 옮겼다
- **WHEN** Space를 누른다
- **THEN** 싱크가 켜지거나 꺼지고 송출 상태는 바뀌지 않는다

#### Scenario: 직접 입력에서 송출 버튼을 누른 뒤

- **GIVEN** 직접 입력에서 운영자가 "자막 보내기" 버튼을 마우스로 눌렀다
- **WHEN** 운영자가 이어서 "2절 주님"을 타자한다
- **THEN** 글은 입력 칸에 들어가고 표시 방식과 송출 상태는 바뀌지 않는다

#### Scenario: 직접 입력 중의 Space

- **GIVEN** 운영자가 직접 입력 칸에 글을 쓰는 중이다
- **WHEN** Space를 누른다
- **THEN** 띄어쓰기가 입력되고 송출 상태는 바뀌지 않는다

### Requirement: 연결·장치 설정은 별도 창

시스템 SHALL OBS 연결, 카메라, 씬 단축키, 브라우저 소스 주소와 추가, 편집 복구, PPT 세부 조정(PPT 열기, 상자 선택, 문구 고치기)을 자막 탭이 아닌 설정 창에 둔다. 자막 탭의 설정 버튼이 설정 창을 열고, 설정 창은 본창이 있는 화면의 작업 영역 안에 열린다. 자막 모양 빠른 조절(줄 수, 악보 크기, 글자색, 배경 상자)과 내보낼 곳은 자막 탭에 남는다.

#### Scenario: 예배 중 화면

- **WHEN** 운영자가 자막 탭만 보고 있다
- **THEN** OBS 암호 입력이나 씬 이름 칸은 보이지 않는다

## REMOVED Requirements

### Requirement: 크게 쓸 수 있는 운영 창

**Reason**: 자막 운영이 본창 미리보기 칸의 탭이 되어 별도 창, 창 크기·위치 기억이 없어진다.

**Migration**: "본창 미리보기 칸의 자막 탭" 요구 사항을 따른다. 프로필의 `caption-window.json`은 읽지 않는다.

### Requirement: 운영 창의 예배 순서

**Reason**: 자막 탭은 본창 안에 있어 본창 예배 순서를 바로 옆에서 쓴다.

**Migration**: 항목은 본창 예배 순서에서 고르고, 미리보기 칸의 "송출 칸에 올리기"·더블클릭·F11 등 본창 동작으로 내보낸다.

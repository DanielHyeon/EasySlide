## ADDED Requirements

### Requirement: 본창 글자는 화면 크기 설정을 따른다

시스템 SHALL 본창의 메뉴, 도구 막대, 곡·예배 순서·검색 목록, 아래 탭, 상황 줄, 문맥 메뉴 글자를 본문 글자 토큰으로 그린다. 본문 글자는 "작게" 10, "표준" 11 DIP이고 "크게"(16.8)와 "시니어"(19.6)는 지금 값 그대로다. 제목·큰 본문 토큰과 송출 화면 글자는 바뀌지 않는다. 고정 높이 칸은 커진 글자를 자르지 않는다.

#### Scenario: 표준 크기

- **GIVEN** 화면 크기가 "표준"이다
- **WHEN** 본창을 연다
- **THEN** 메뉴, 예배 순서, 곡 목록, 아래 탭 글자는 11 DIP다

#### Scenario: 작게로 바꾸기

- **GIVEN** 본창이 열려 있다
- **WHEN** 설정에서 화면 크기를 "작게"로 바꾼다
- **THEN** 메뉴, 예배 순서, 곡 목록, 아래 탭 글자가 10 DIP가 된다

### Requirement: 좁은 본창에서 글자가 겹치거나 중간에서 잘리지 않는다

시스템 SHALL 본창 폭이 줄어도 아래 탭 글자 위에 스크롤바를 그리지 않고 탭을 여러 줄로 감싸며, 예배 순서 제목과 상황 줄 오른쪽 글은 넘치면 말줄임(…)으로 끝낸다. 상황 줄의 글들은 서로 붙지 않는다.

#### Scenario: 최소 크기의 아래 탭

- **GIVEN** 본창이 최소 크기(780×540)다
- **WHEN** 운영자가 왼쪽 아래 탭을 본다
- **THEN** 여섯 탭이 모두 보이고 탭 글자 위에 스크롤바가 없다

#### Scenario: 긴 예배 순서 제목

- **GIVEN** 예배 순서에 "621장_찬양하라_내_영혼아_새찬송가악보_PPTX.pptx"가 있고 왼쪽 칸이 좁다
- **WHEN** 운영자가 예배 순서를 본다
- **THEN** 제목은 목록 폭 안에서 말줄임(…)으로 끝나고 글자 중간이 잘리지 않는다

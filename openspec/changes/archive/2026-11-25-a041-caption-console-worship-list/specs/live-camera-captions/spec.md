## ADDED Requirements

### Requirement: 운영 창의 예배 순서

시스템 SHALL 운영 창에 본창과 같은 예배 순서 목록과 "송출" 버튼을 보여 준다(따라가기에서는 따라가기 조작 아래, 직접 입력에서는 입력 칸·자막 송출 버튼 아래). 목록에서 고르면 본창 예배 순서에서 고른 것과 같고 송출 화면은 바뀌지 않는다. 송출 중인 항목에는 LIVE 표시가 있다. "송출" 버튼, 항목 더블클릭, 키보드로 고른 목록의 Enter는 본창 예배 순서 더블클릭과 같은 동작이다. 목록은 그 안에서 스크롤하며 다른 조작을 가리지 않고, 직접 입력 칸은 최소 3줄 높이다. 마우스로 고른 뒤의 키는 지금처럼 자막에 쓰인다.

#### Scenario: 다음 곡 송출

- **GIVEN** 운영 창이 최대화되어 있고 자막이 송출 화면의 1번 곡을 따라가는 중이다
- **WHEN** 운영자가 운영 창 예배 순서에서 2번 곡을 고르고 "송출"을 누른다
- **THEN** 송출 화면에 2번 곡이 나가고, 2번 곡에 LIVE 표시가 있으며, 자막은 2번 곡을 따라간다

#### Scenario: 항목 더블클릭과 빈 곳 더블클릭

- **GIVEN** 송출 화면에 1번 곡이 나가는 중이다
- **WHEN** 운영자가 운영 창 예배 순서의 빈 곳을 더블클릭한 뒤 2번 곡을 더블클릭한다
- **THEN** 빈 곳 더블클릭으로는 아무것도 송출되지 않고, 2번 곡 더블클릭으로 2번 곡이 송출된다

#### Scenario: 고르기만 한 항목

- **GIVEN** 송출 화면에 1번 곡이 나가는 중이다
- **WHEN** 운영자가 운영 창 예배 순서에서 3번 항목을 누르기만 한다
- **THEN** 본창 예배 순서에서도 3번 항목이 선택되고 송출 화면과 자막은 1번 곡 그대로다

#### Scenario: 항목을 누른 뒤의 Space

- **GIVEN** 운영자가 운영 창 예배 순서에서 항목을 마우스로 눌렀다
- **WHEN** Space를 누른다
- **THEN** 자막 송출/숨김이 바뀌고 예배 순서 선택은 그대로다

#### Scenario: 직접 입력 중 송출

- **GIVEN** 직접 입력으로 "환영합니다"를 송출 중이다
- **WHEN** 운영자가 운영 창 예배 순서에서 2번 곡을 고르고 "송출"을 누른 뒤 "2절"을 타자한다
- **THEN** 송출 화면에 2번 곡이 나가고, 자막은 "환영합니다" 그대로이며, "2절"은 입력 칸에 들어간다

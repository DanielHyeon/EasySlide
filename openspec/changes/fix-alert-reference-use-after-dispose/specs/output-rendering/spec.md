# output-rendering

## ADDED Requirements

### Requirement: 알림은 준비하는 도중에 자원을 잃지 않는다

메시지 알림과 부모 호출 알림을 시작하면 알림 글자가 송출 화면에 나와야 한다(SHALL). 준비 과정은 해제된 그리기 객체를 쓰면 안 된다(SHALL NOT).

#### Scenario: 쇼 진행 중에 메시지 알림

- **GIVEN** 쇼가 진행 중이다
- **WHEN** 메시지 알림을 보낸다
- **THEN** 알림 글자가 송출 화면에 나온다
- **AND** 예외가 나지 않고, 송출 창이 새 창으로 바뀌지 않는다

#### Scenario: 알림을 준비하다 실패한다

- **WHEN** 알림 글자가 비어 있거나 공백뿐이거나, 글꼴 크기가 너무 작아 알림을 만들 수 없다
- **THEN** 알림은 나오지 않는다
- **AND** 예외가 호출한 쪽으로 나가지 않고, 송출 창이 새 창으로 바뀌지 않는다
- **AND** 실패 이유가 기록된다

#### Scenario: 알림을 여러 번 보낸다

- **WHEN** 알림을 보내고, 끝난 뒤 다른 글자로 다시 보낸다
- **THEN** 두 번 모두 정상으로 나온다
- **AND** 첫 알림의 비트맵은 해제된다

### Requirement: 참조 표시는 송출 화면을 깨뜨리지 않는다

참조 표시를 켜면 참조 글자가 송출 화면에 나와야 한다(SHALL). 참조 표시 때문에 송출 화면에 빨간 X나 오류 창이 나오면 안 된다(SHALL NOT).

#### Scenario: 쇼 진행 중에 참조 표시

- **GIVEN** 쇼가 진행 중이고 글자 항목이 나가고 있다
- **WHEN** 참조 표시를 켠다
- **THEN** 참조 글자가 송출 화면에 나온다
- **AND** 빨간 X와 오류 창이 나오지 않는다

#### Scenario: 참조 표시 뒤에 슬라이드를 넘긴다

- **WHEN** 참조 표시를 켠 채로 슬라이드를 여러 장 넘기고 항목을 바꾼다
- **THEN** 화면이 계속 정상으로 그려진다

#### Scenario: 참조 글자가 비어 있다

- **WHEN** 참조 글자가 비어 있거나 공백뿐인 상태에서 참조 표시를 켠다 (옵션의 참조 표시 내용이 "없음"인 기본 설정에서 참조 표시 버튼이나 Z 키를 누르는 경우 포함)
- **THEN** 화면에 아무것도 나오지 않는다. 빈 상자도 나오지 않는다
- **AND** 오류도 나지 않는다

### Requirement: 알림과 참조 표시의 자원은 쌓이지 않는다

알림이나 참조 표시를 새로 준비할 때 이전에 만든 비트맵은 해제돼야 한다(SHALL). 컨트롤이 해제될 때 남은 비트맵도 해제돼야 한다(SHALL).

#### Scenario: 예배 한 번 동안 여러 번

- **WHEN** 알림과 참조 표시를 수십 번 반복한다
- **THEN** 화면에 쓰이지 않는 이전 비트맵이 남아 있지 않다

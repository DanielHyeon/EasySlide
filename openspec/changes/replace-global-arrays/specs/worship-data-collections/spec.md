# 예배 자료 목록과 설정의 호환성

## ADDED Requirements

### Requirement: 예배 순서를 문서로 만들 때 항목 순서 보존

예배 순서에서 문서를 만들 때는 첫 항목부터 마지막 항목까지 목록 순서와 항목별 제목을 유지해야 한다(SHALL).

#### Scenario: 여러 항목이 있는 예배 순서를 문서로 만든다

- **GIVEN** 예배 순서에 제목이 서로 다른 찬양 세 곡이 있다.
- **WHEN** 운영자가 현재 예배 순서를 문서로 만든다.
- **THEN** 문서의 첫째, 둘째, 셋째 곡 제목이 예배 순서의 같은 위치에 있는 곡과 각각 일치한다.

### Requirement: 폴더 옵션 편집본의 독립성

폴더 옵션 편집본의 제목, 두 번째 영역 글꼴, 스타일, 줄 간격은 원본과 독립적으로 변경할 수 있어야 한다(SHALL).

#### Scenario: 폴더 옵션 편집을 취소한다

- **WHEN** 운영자가 폴더 제목과 두 번째 영역 글꼴, 줄 간격을 바꾼 뒤 적용하지 않고 취소한다.
- **THEN** 원본 폴더에는 편집 전 제목과 글꼴, 줄 간격이 그대로 남는다.

### Requirement: 기존 곡의 라이선스 관리자 이름 표시

곡 편집기의 두 라이선스 관리자 선택 목록은 등록된 사용자 정의 항목을 모두 제공하고, 기존 곡에 저장된 미등록 이름도 그대로 읽을 수 있어야 한다(SHALL).

#### Scenario: 기존 곡에 미등록 관리자 이름이 들어 있다

- **WHEN** 기본 관리자와 보조 관리자에 서로 다른 미등록 이름이 있는 곡을 읽는다.
- **THEN** 양쪽 모두 저장된 이름 그대로 표시된다.

#### Scenario: 마지막 두 사용자 정의 관리자를 선택한다

- **WHEN** 7번과 8번에 관리자를 등록하고 기본·보조 관리자 선택 목록을 연다.
- **THEN** 두 목록 모두에 두 관리자가 보이고 각각 해당 관리자의 라이선스 표시 문구로 변환된다.

### Requirement: PPT 장수에 따른 미리보기·송출 썸네일 목록

미리보기·송출 패널은 현재 PPT의 슬라이드 수에 맞춰 썸네일을 표시하고 각 패널의 선택을 독립적으로 관리해야 한다(SHALL).

#### Scenario: 1,024장을 넘는 PPT의 마지막 장을 미리 본다

- **WHEN** 1,024장 PPT를 1,025장 PPT로 바꾼 뒤 미리보기에서 마지막 썸네일을 선택한다.
- **THEN** 1,025번째 슬라이드를 미리 볼 수 있고 송출 패널의 선택은 유지된다.

#### Scenario: 더 짧은 PPT를 연다

- **WHEN** 1,025장이 표시된 패널에서 3장 PPT를 연다.
- **THEN** 새 PPT의 썸네일 세 개만 남고 이전 PPT의 4번째 이후 썸네일은 선택할 수 없다.

# WPF 카메라·마이크·OBS 점검

## Why

예배 전이나 송출 중에 운영자가 옵션에서 카메라 신호와 마이크 입력 유무를 확인할 수 있어야 한다. 장치가 표시되는 것과 실제 신호 수신을 구분한다.

## What Changes

- WPF 옵션에 장치 목록, 카메라 시험 영상, 마이크 음소거 상태와 실시간 입력 레벨을 표시하는 장치 점검 탭을 추가한다.
- 점검은 선택한 장치에서만 명시적으로 시작하며 탭을 떠나면 자원을 해제한다. 사용 중인 송출 카메라에는 소유권 우선권을 준다.

- OBS 제어 연결 상태와 프로그램 씬을 표시한다. 운영자는 설정된 로컬 WebSocket 서버에 일회성 연결 시험을 실행할 수 있다.

## Capabilities

### New Capabilities

- `device-diagnostics` 운영자 로컬 장치 점검

## Impact

WPF 설정 창, DirectShow 캡처와 Windows Core Audio 입력 장치가 대상이다. 점검용 선택은 예배 설정에 저장하지 않는다.

## 4. 현장 동작 확인

- [x] 4.1 실제 Windows 장치 열거와 WPF 화면을 확인하고 실물 신호 검증 범위를 기록

## 검증 결과

- Release 빌드 성공. 격리된 HKCU로 전체 테스트 2,849개 통과(WPF 2,594개, 분석기 20개, 기존 앱 235개).
- 실제 WPF 설정 창에서 기본 크기 1040×720 및 최소 크기 920×620으로 왼쪽 탐색과 카메라·마이크·OBS 결과 표시 영역을 확인했다.
- 점검 PC에는 카메라와 활성 오디오 입력 장치가 없었고 기본 OBS 포트에서 응답이 없었다. 실물 영상 및 음성 입력은 미검증이다. 장치 대역으로 프레임·레벨·탭 이탈을, 로컬 프로토콜 서버로 인증 성공·거부·씬 조회·시간 초과·취소와 제어 세션 유지를 검증했다.

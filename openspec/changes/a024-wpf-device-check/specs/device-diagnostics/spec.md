# 장치 점검

## Purpose

운영자가 예배 송출 전이나 진행 중에 같은 옵션 화면에서 연결된 영상 입력 장치와 마이크를 확인하고 실제 영상 및 소리 입력을 시험할 수 있도록 한다.

## ADDED Requirements

### Requirement: 카메라 연결 점검
시스템 SHALL 옵션에서 카메라 이름과 시험 영상을 표시하고 실제 프레임 수신 여부를 구분한다.

#### Scenario: 선택한 카메라 시험
- **WHEN** 운영자가 카메라를 골라 영상 확인을 누른다
- **THEN** 선택한 카메라에서 프레임이 도착하면 영상과 수신 상태를 표시하고, 장치 부재·신호 소실·접근 실패는 상태 문구로 표시한다.

#### Scenario: 송출 카메라 사용 중
- **WHEN** 앱이 로컬 카메라를 사용하거나 OBS 카메라 모드를 선택했다
- **THEN** 점검 화면은 카메라를 추가로 열지 않는다. 송출이 점검 도중 시작되면 점검 장치를 양보한다.

### Requirement: 마이크 입력 점검
시스템 SHALL 선택한 Windows 마이크의 음소거와 실시간 입력 레벨을 표시한다.

#### Scenario: 소리와 무음 구별
- **WHEN** 운영자가 입력 점검을 시작해 말하거나 마이크를 음소거한다
- **THEN** 입력 레벨과 음소거 상태를 표시하고, 장치 접근 실패와 무음인 상태를 구분한다.

### Requirement: OBS 연결 점검
시스템 SHALL 현재 OBS 제어 연결 상태와 프로그램 씬을 표시하고, 로컬 WebSocket 서버에서 실제 프로그램 씬을 조회하는 일회성 점검을 제공한다.

#### Scenario: 연결된 OBS에서 씬 변경
- **WHEN** 운영자가 OBS에서 프로그램 씬을 바꾼다
- **THEN** 열린 점검 탭이 OBS 연결 이벤트를 받아 현재 씬을 갱신한다.

#### Scenario: 수동 연결 확인
- **WHEN** 운영자가 연결 확인을 선택한다
- **THEN** 설정된 포트에서 OBS v5 인증 및 읽기 전용 씬 조회 결과를 표시한다. 서버 미실행, 인증 거부, 응답 시간 초과를 안내하고 기존 제어 세션과 방송 설정을 유지한다.

### Requirement: 점검 종료와 격리
시스템 SHALL 장치 점검 선택과 캡처 수명을 옵션 화면으로 제한한다.

#### Scenario: 탭 이동 또는 장치 교체
- **WHEN** 운영자가 장치를 바꾸거나 점검을 중지하거나 탭·창을 떠난다
- **THEN** 해당 점검 자원을 해제하고 영상과 레벨을 지운다. 예배 송출 설정과 운영 레지스트리를 변경하지 않는다.

# Tasks: 예배 순서 목록의 끌어다 놓기

구현 → 적대적 리뷰 → 내장 코드 리뷰 → 총괄 검증 → 커밋.

## 1. 먼저 확인할 것

- [ ] 1.1 시험용 목록으로 앱을 띄우는 절차가 실제 목록과 설정을 건드리지 않는지 (예배 목록 폴더, 레지스트리에 쓰이는 값)
- [ ] 1.2 수정 전 빌드에서 사고의 재현: 시험용 목록에서 첫 줄 클릭이 끌기로 처리되면 항목이 맨 끝으로 가는가
- [ ] 1.3 `DragOver`가 적는 값이 화면 표시에 쓰이는지 (삽입 위치 표시가 있는지)
- [ ] 1.4 다른 목록의 `ItemDrag`가 넘기는 선택 항목이 실제 결과에 영향을 주는지 (W5)

## 2. 구현

- [ ] 2.1 W1: 놓는 위치를 놓은 좌표에서 구한다
- [ ] 2.2 W2: 순서가 바뀌지 않는 놓기는 아무것도 하지 않는다
- [ ] 2.3 W3: 끄는 동안의 값 정리
- [ ] 2.4 W5: 다른 목록에서 끌 때의 선택 항목 (확인 결과에 따라)

## 3. 확인 (모두 시험용 목록에서)

- [ ] 3.1 사고를 낸 클릭을 되풀이해도 목록 파일이 바뀌지 않는다
- [ ] 3.2 줄을 다른 줄 위에 놓으면 그 줄 앞에 들어가고 저장된다
- [ ] 3.3 끌던 줄 위에 놓으면 파일이 다시 쓰이지 않고, 송출·미리보기 표시가 그대로다
- [ ] 3.4 마지막 줄 아래에 놓으면 맨 끝으로 간다. 줄이 잡히지 않는 다른 자리에서는 아무 일도 없다
- [ ] 3.5 여러 줄을 골라 끌기, 찬양 목록에서 끌어 넣기, Delete 키, 위아래 옮기기 버튼이 수정 전과 같다
- [ ] 3.6 실제 목록 32개의 해시와 레지스트리가 시험 전과 같다. 시험용 목록은 지웠다

# worship-list

## ADDED Requirements

### Requirement: 선택한 줄의 항목이 미리보기에 올라간다

예배 순서 목록에서 줄을 선택하면, 미리보기 단에는 그 줄에 지금 들어 있는 항목이 올라가야 한다(SHALL). 직전에 같은 번호의 줄을 선택했더라도 그 줄의 항목이 달라졌으면 다시 불러와야 한다(SHALL).

#### Scenario: 순서를 바꾼 뒤 같은 번호의 줄을 선택한다

- **GIVEN** 3번째 줄의 PPT A를 선택했다가 위로 옮겼다 (3번째 줄에는 이제 PPT B가 있다)
- **WHEN** 3번째 줄을 선택한다
- **THEN** 미리보기 단의 제목과 썸네일은 B다
- **AND** 송출로 보내면 송출 단에 B가 올라가고 목록의 송출 표시도 B 줄에 붙는다

#### Scenario: 다른 예배 목록으로 바꾼 뒤

- **GIVEN** 어떤 줄의 PPT를 선택했다가 다른 예배 목록으로 바꿨다
- **WHEN** 같은 번호의 줄을 선택한다
- **THEN** 미리보기에는 새 목록의 그 줄 항목이 올라간다

#### Scenario: 같은 항목을 다시 선택한다

- **WHEN** 썸네일이 만들어진 PPT 줄을 선택한 뒤, 목록을 바꾸지 않고 같은 줄을 다시 선택한다
- **THEN** 이 수정 전과 같이 다시 불러오지 않는다 (느려지지 않는다)

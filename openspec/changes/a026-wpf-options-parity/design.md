## Context

WinForms 기준은 FrmOptions.Designer의 탭·그룹과 FrmOptions_Load, BtnOK_Click, SaveVariables의 동작이다. WPF는 JSON 설정, 성경 카탈로그와 곡 DB를 사용한다.

## Decisions

WPF의 View → Options는 메인 창이 소유하는 WPF SettingsWindow 한 개를 연다. 여덟 탭의 컨트롤 위치는 WinForms 디자이너를 따르고 도구 모음은 같은 Fluent 아이콘 경로를 사용한다. 하단의 WPF 설정 및 장치 점검 버튼은 같은 창에서 관리 탭으로 전환한다. 확인하면 WPF 설정 초안에서 변경한 키를 JSON에 병합한다. 폴더와 성경 목록은 옵션 창에서 확인한 편집만 해당 데이터베이스에 반영한다.

## WinForms 옵션 대응표

비교 기준은 `FrmOptions.Designer.cs`의 사용자 조작 항목, `FrmOptions.cs`의 로드·확인 처리, WPF 설정 키를 실제로 읽는 화면과 송출 코드다. 탭 순서 일치와 송출 결과 일치를 별도로 확인했다.

| 탭 | 확인 후 적용되는 동작 |
| --- | --- |
| 메인 화면 | 미리보기와 송출의 가사 목록에서 글자 크기, 선택색, 포커스 배경과 화면 사이 선을 갱신한다. 최근 편집 메뉴가 라이브러리별 설정 개수를 사용하고 A/B/C 바로가기는 폴더 이름으로 선택한다. |
| 송출 | 항목 넘김·간격·문단 표시 외에 가사 영역의 글꼴 맞춤, 구분선, 이어지는 줄 들여쓰기와 코드 글꼴 배율을 적용한다. 영상은 크기 비율과 위·가운데·아래 정렬에 따라 배치한다. 송출 창의 수명에 맞추어 Windows 디스플레이 전원 요청과 화면 보호기 메시지 처리를 시작하고 해제한다. |
| 모니터 | 회중과 가사 모니터의 사용자 좌표·폭을 독립 계산한다. 가로세로비에 따른 높이를 보여주고 연결된 화면 및 송출 영역과의 교차를 검사한다. 가사 창의 코드 표시와 글자·코드 크기, 색상, 강조 서식을 독립 적용한다. 카메라에는 전용 와이드·패널·음량·밸런스·음소거 설정이 있다. 캡처 장치가 내장 오디오 핀을 제공하면 해당 그래프에 적용한다. 별도 마이크 선택과 OBS·스피커 라우팅은 송출 화면에서 조작한다. |
| 알림 | 회중 메시지, 보호자 호출, 항목 참조가 각자의 글꼴, 크기, 강조, 그림자, 외곽선, 전경·배경색과 위치를 사용한다. 같은 위치에 오는 회중 메시지와 보호자 호출은 세로로 쌓인다. |
| 폴더 | 두 가사 영역과 제목의 서식, 영역 위치, 간격과 여백을 편집한다. 위치 샘플이 변경값을 즉시 표시한다. 하위 편집기의 저장은 옵션 초안에 반영하고, 바깥 확인에서 바뀐 폴더들을 한 SQLite 트랜잭션으로 저장한다. |
| 성경 | 목록 추가·숨김·이름·순서와 버전별 연결 폴더·글자 비율을 임시 카탈로그에서 편집한다. 확인 시 카탈로그의 동시 변경을 검사하고 변경 행을 한 트랜잭션으로 반영한다. 선택한 버전별 폴더 글꼴과 비율을 미리보기 항목 및 회중 송출에 전달한다. |
| 라이선스 | 관리자 이름·번호와 표시 예시, 첫 화면 표시를 제공한다. AdminDB의 LICENCE 관리자 4~8번을 처음 열 때 비어 있는 이름의 초깃값으로 제시하고, 확인 시 DB 경로와 함께 저장하여 다음 실행에서 사용자가 지운 이름을 복원하지 않는다. |
| 키보드 | 두 배열의 항목 이동·슬라이드 이동 키를 가사와 PPT에 적용한다. F7~F10, 위·아래, Ctrl+위·아래 전역 사용을 조절하고, 개별 사용자 단축키를 포함한 활성 등록 목록을 확인 시 교체한다. |

WPF 설정은 JSON을 사용한다. 폴더와 성경의 확인 처리는 서로 다른 SQLite 파일에 각각 커밋한다. 한 저장소에서 오류가 발생하면 이유를 표시하며 같은 대화상자에서 다시 시도할 수 있다.

## Verification

임시 JSON 및 SQLite 파일로 미확정 편집의 격리, 변경한 설정만 병합하기, 성경 목록의 취소·저장·동시 편집 충돌을 검증한다. WPF 컨트롤 테스트에서는 실제 측정·배치와 비트맵 렌더링으로 코드 줄 크기와 줄바꿈, 동시 알림 위치를 확인한다. Release 솔루션 빌드 오류 0건. HKCU를 격리한 전체 테스트 2,870개 통과(2,615 + 20 + 235). 임시 프로필로 실제 WPF 설정 창을 800×620 DIP에서 열어 10개 탭을 확인하고, 미리보기 글자 크기·최대 글꼴·가사 모니터 사용자 배치·보호자 호출 굵게를 편집했다. 확인 전후 설정과 실제 송출 창의 가사·호출 표시를 점검했다.

운영 장비의 캡처 드라이버·물리 출력과 Windows 화면 보호기 정책은 장비별 현장 검증 대상이다.

# song-library

## ADDED Requirements

### Requirement: WPF 앱은 폴더의 정렬 방식을 잃지 않는다

WPF 앱이 폴더를 저장할 때, 저장된 정렬 방식(제목순 0, 글자 수순 1, 번호순 2)은 사용자가 정렬을 바꾼 경우가 아니면 그대로 남아야 한다(SHALL).

#### Scenario: 번호순 폴더의 이름을 바꾼다

- **GIVEN** 폴더의 정렬 방식이 번호순(2)이다
- **WHEN** 폴더 편집기에서 이름을 바꾸고 저장한다
- **THEN** 정렬 방식은 번호순(2)으로 남는다

#### Scenario: 글자 수순 폴더를 끈다

- **GIVEN** 폴더의 정렬 방식이 글자 수순(1)이다
- **WHEN** 폴더 편집기에서 사용 여부를 바꾸고 저장한다
- **THEN** 정렬 방식은 글자 수순(1)으로 남는다

### Requirement: 번호순 폴더는 곡 번호순으로 열린다

정렬 방식이 번호순(2)인 폴더를 고르면 곡 목록은 곡 번호순이어야 한다(SHALL).

#### Scenario: 번호순 폴더를 고른다

- **WHEN** 정렬 방식이 2인 폴더를 고른다
- **THEN** 곡 목록이 곡 번호순으로 보인다

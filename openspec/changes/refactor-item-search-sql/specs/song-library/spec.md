# 곡 검색

## ADDED Requirements

### Requirement: 곡 번호와 검색 문구의 일치 조건

곡 검색은 선택한 검색 항목 중 하나라도 일치하는 곡을 찾아야 한다(SHALL). 곡 번호는 양의 정수로 정확히 일치해야 하며, 문구에 포함된 따옴표도 검색할 수 있어야 한다(SHALL).

#### Scenario: 곡 번호만 선택한다

- **WHEN** 곡 번호만 선택해 `221`을 검색한다.
- **THEN** 선택한 폴더와 필터 범위에서 번호가 221인 곡만 나온다.
- **AND** 같은 조건에서 `0`이나 숫자가 아닌 문구를 검색하면 결과가 비어 있다.

#### Scenario: 제목에 따옴표가 들어 있다

- **WHEN** 제목 검색란에 따옴표를 포함한 문구를 입력한다.
- **THEN** 해당 문구가 제목에 포함된 곡을 정상적으로 조회할 수 있다.

#### Scenario: 별표가 포함된 검색의 개수를 표시한다

- **WHEN** 별표를 포함한 문구와 일치하는 곡이 있는 상태에서 찾기를 실행한다.
- **THEN** 찾기 목록에는 일치하는 곡이 보이고 표시된 개수는 그 목록의 곡 수와 같다.

### Requirement: 검색 항목과 추가 필터의 조합

곡 검색은 폴더, 조, 박자, 악보 유무와 수정일 필터를 함께 적용해야 한다(SHALL). 검색 항목을 하나도 고르지 않은 경우에는 ‘악보만’을 선택했을 때만 필터에 맞는 결과를 표시해야 한다(SHALL).

#### Scenario: 특정 폴더에서 악보가 있는 곡만 찾는다

- **WHEN** 검색 항목을 모두 해제하고 한 폴더와 ‘악보만’, 조, 박자를 선택한다.
- **THEN** 그 폴더 안에서 악보가 있고 지정한 조와 박자가 모두 일치하는 곡만 보인다.
- **AND** ‘악보만’도 해제하면 결과가 비어 있다.

### Requirement: 지역 형식과 관계없는 수정일 검색

수정일 검색은 시작일과 종료일을 모두 포함하며 저장된 시각과 Windows의 한국어·영어 지역 형식에 관계없이 같은 날짜 범위를 적용해야 한다(SHALL).

#### Scenario: 이전 버전에서 저장한 날짜로 검색한다

- **GIVEN** 이전 버전의 한국어 또는 영어 날짜 형식으로 수정일이 저장된 곡이 있다.
- **WHEN** 앱 시작 후 해당 수정일을 시작일 또는 종료일로 지정해 검색한다.
- **THEN** 해당 곡이 결과에 포함되고 날짜 범위 밖의 곡은 제외된다.

#### Scenario: 찾기 창을 다시 연다

- **WHEN** 이전 버전에서 한국어 형식으로 저장한 시작일과 영어 형식으로 저장한 종료일이 있는 상태에서 찾기 창을 연다.
- **THEN** 두 날짜 선택기에 각각 저장했던 날짜가 표시된다.

## 확인 못 한 것

- 실제 Windows 종료와 로그오프. 시험은 보이는 두 창에 메시지를 보내는 방식이었다.
- 단일 모니터 방식(모달 쇼)의 종료 경로. 이 PC에서는 설정을 바꾸지 않고 실행할 수 없다. WinForms의 동작은 별도 시험 프로그램으로 확인했다.
- 알림(`StartAlert`) 경로의 화면. 알림 창에 입력해야 띄울 수 있다. 글꼴 해제는 코드 검토와 참조 표시 경로의 실행으로만 확인했다.
- 전환 효과가 켜진 평소 실행. 이 PC의 전환 설정은 "없음"이다.
- 사각형 전환의 첫 프레임(진행 0%)과 너비가 홀수인 화면.

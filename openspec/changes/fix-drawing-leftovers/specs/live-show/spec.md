# live-show

## ADDED Requirements

### Requirement: 사각형 전환은 두 그림을 함께 보여 준다

`Rectangle`, `RectangleIn` 전환이 진행되는 동안 화면에는 이전 그림과 새 그림이 사각형 경계를 사이에 두고 함께 보여야 한다(SHALL).

#### Scenario: 사각형 전환 도중

- **GIVEN** 전환 효과가 `Rectangle`로 정해져 있다
- **WHEN** 다음 슬라이드로 넘긴다
- **THEN** 전환 시간 동안 가운데 사각형 안에 새 그림이, 바깥에 이전 그림이 보이고, 사각형이 커지며 끝난다

### Requirement: 화면을 오래 써도 그림 자원이 쌓이지 않는다

슬라이드를 넘기거나 알림, 참조 표시를 켜고 끄는 일을 되풀이해도, 앱이 만든 그림과 글꼴 객체는 쓰고 난 뒤 해제되어야 한다(SHALL). 전환 프레임이 실패해도 그 프레임이 만든 자원은 해제된다.

#### Scenario: 슬라이드를 많이 넘긴다

- **WHEN** 가사 슬라이드와 PPT 슬라이드를 각각 50번 넘긴다
- **THEN** 앱의 메모리와 GDI 객체 수가 넘기기 전과 같은 수준에 머문다 (GC를 강제하지 않고)

### Requirement: 쇼 진행 중에 앱을 닫아도 쇼가 정리된다

쇼가 진행 중일 때 앱을 닫으면 앱은 쇼를 정상 경로로 끝낸 뒤 종료해야 한다(SHALL).

#### Scenario: 쇼 진행 중에 앱을 닫는다

- **GIVEN** PPT 항목이 송출 중이다
- **WHEN** 메인 화면을 닫는다
- **THEN** 출력 모니터에 슬라이드 쇼 창이 남지 않고, 작업 표시줄과 화면 보호기 설정이 쇼 이전 상태로 돌아가며, PowerPoint가 숨은 채 남지 않는다

### Requirement: 닫히지 않는 닫기 요청은 아무것도 닫지 않는다

메인 화면의 닫기가 취소됐거나, Windows가 종료해도 되는지 묻기만 한 단계에서는, 앱은 쇼를 끝내거나 PowerPoint를 놓거나 설정을 정리하지 않아야 한다(SHALL NOT). 종료가 확정되면 닫기 작업을 한 번 실행하고, 그때 설정 저장을 가장 먼저 한다.

#### Scenario: Windows 종료가 취소된다

- **GIVEN** PPT 항목이 송출 중이다
- **WHEN** Windows가 종료를 물었다가 종료가 취소된다
- **THEN** 프로젝터의 화면이 그대로이고, 슬라이드를 계속 넘길 수 있다

#### Scenario: 취소된 종료 뒤에 송출 창이 닫기 요청을 받는다

- **GIVEN** Windows 종료가 한 번 취소됐고 쇼가 진행 중이다
- **WHEN** 작업 관리자가 송출 창에 닫기를 보낸다
- **THEN** 쇼는 메인 화면을 거쳐 끝나고, 메인 화면의 쇼 버튼이 꺼진 상태가 된다

#### Scenario: Windows 종료가 확정된다

- **WHEN** Windows 종료가 확정된다
- **THEN** 창 상태 설정이 저장되고, 닫기 작업은 한 번만 실행된다

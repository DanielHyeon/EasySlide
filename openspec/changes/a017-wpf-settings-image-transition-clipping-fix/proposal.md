# 제안

## 배경

설정 패널의 일부 텍스트 박스와 체크박스 잘림은 `a016`에서 보정했지만, 사용자 확인 결과 선택 항목 설정의 `Image` 경로 텍스트와 `Transition` 영역의 콤보박스 텍스트가 여전히 하단에서 잘려 보인다.

## 변경 목표

- Default/Individual 설정 패널의 Transition 콤보박스가 같은 높이와 세로 패딩 기준을 사용한다.
- 선택 항목의 Image/Media 경로 텍스트 박스가 설정 전용 compact 텍스트 박스 스타일을 사용한다.
- 변경 후 렌더 캡쳐 증거로 하단 획이 있는 글자가 잘리지 않는지 확인한다.

## 비목표

- 전환 효과 로직, 송출 로직, 배경 이미지 선택 로직은 변경하지 않는다.
- WinForms 레거시 화면은 변경하지 않는다.
- 설정 저장 모델과 ViewModel 내부 함수 로직은 변경하지 않는다.

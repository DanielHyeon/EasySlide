## ADDED Requirements

### Requirement: 데스크톱 목록과 저장소의 안정적인 식별
앱은 선택되지 않은 탭을 안전하게 처리하고 숨김을 해제한 탭을 기준 탭 다음에 복원해야 한다(SHALL). 이름에는 전체 문자열 비교를 적용하고, 기술 식별자와 PPT 파일 연결은 사용자의 언어나 코드 페이지에 독립적으로 처리해야 한다(SHALL).

#### Scenario: 탭을 숨긴 뒤 다시 표시
- **WHEN** 운영자가 PPT 또는 미디어 탭을 숨긴 다음 다시 표시한다.
- **THEN** 기준 탭 다음의 원래 순서가 복원되며 선택된 페이지가 없는 동안 선택 조회는 false를 반환한다.

#### Scenario: 이름 변경 및 열 생성
- **WHEN** 성경이나 폴더 이름을 바꾸거나 SQLite에 Timing 열을 추가한다.
- **THEN** 다른 항목의 전체 이름만 중복으로 판단하며 마지막 폴더까지 검사하고 TIMING 보조 열을 일관되게 생성한다.

#### Scenario: Unicode 설치 경로에서 PPT 사용
- **WHEN** Unicode 문자가 포함된 경로에서 PPT 파일 연결을 확인한다.
- **THEN** Windows가 보고한 파일 연결 상태를 반환한다.

# Proposal: 옵션 창의 아이콘을 현대 모습으로 바꾼다

## Why

메인 화면은 현대 모습에서 Fluent UI System Icons의 단색 아이콘을 쓴다 (`modernize-main-form-ui` D18~D25). 옵션 창(`FrmOptions`)은 예전의 컬러 비트맵 아이콘이 그대로여서, 메인 화면에서 옵션 창을 열면 모습이 어긋난다.

## What Changes

- 현대 모습이 켜져 있을 때, 옵션 창의 아이콘을 메인 화면과 같은 아이콘으로 바꾼다.
  - 도구 모음 28개의 단추와 드롭다운, 그 메뉴 항목 (굵게, 기울임, 밑줄, 그림자, 외곽선, 정렬, 세로 정렬, 스크롤, 깜박임, 투명, 오른쪽에서 왼쪽 등)
  - 아이콘이 있는 일반 단추 (위치 고르기, 모니터 정보 등)
  - 목록의 아이콘 (폴더 목록의 사용/미사용, 성경 목록)
- 같은 뜻의 단추는 메인 화면에서 쓰는 아이콘 이름을 그대로 쓴다.
- 현대 모습이 꺼져 있거나 고대비 모드이면 지금 그대로다.

## Out of Scope

- 옵션 창의 배치, 글꼴, 색, 탭 구성.
- 옵션의 동작과 저장.
- 다른 창 (찾기, 편집기 등).

## Impact

- `Easislides/Easislides/FrmOptions*.cs` (새 부분 파일 하나), 필요하면 `Easislides/Global/ModernIcons.cs` (새 아이콘 경로)
- 사용자 영향: 현대 모습에서 옵션 창의 아이콘이 바뀐다. 기능은 같다.

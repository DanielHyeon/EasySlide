# options-window

## ADDED Requirements

### Requirement: 현대 모습에서 옵션 창의 아이콘은 메인 화면과 같은 묶음이다

현대 모습이 켜져 있으면 옵션 창의 도구 모음 단추, 드롭다운과 그 메뉴 항목, 아이콘이 있는 단추, 목록의 아이콘은 메인 화면이 쓰는 단색 아이콘 묶음으로 그려야 한다(SHALL). 같은 뜻의 단추는 메인 화면과 같은 아이콘이어야 한다(SHALL). 단추의 동작, 누름 상태, 툴팁은 달라지지 않아야 한다(SHALL).

#### Scenario: 현대 모습에서 옵션 창을 연다

- **GIVEN** 현대 모습이 켜져 있다
- **WHEN** 옵션 창을 열고 탭을 넘겨 본다
- **THEN** 모든 탭의 아이콘이 단색 아이콘이다
- **AND** 굵게, 기울임, 밑줄, 정렬 단추의 아이콘이 메인 화면의 것과 같다

#### Scenario: 눌린 단추를 알아볼 수 있다

- **WHEN** 켜져 있는 설정의 단추(예: 굵게)를 본다
- **THEN** 눌린 상태와 아닌 상태가 구별된다

### Requirement: 현대 모습이 꺼져 있으면 옵션 창은 그대로다

현대 모습이 꺼져 있거나 고대비 모드이면 옵션 창의 아이콘과 모양은 이 변경 전과 같아야 한다(SHALL).

#### Scenario: 기존 모습

- **GIVEN** 현대 모습이 꺼져 있다
- **WHEN** 옵션 창을 연다
- **THEN** 예전의 컬러 아이콘이 그대로 보인다

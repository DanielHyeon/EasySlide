# Proposal

## Why

WinForms에서 연결이 바뀌면 송출 위치가 잘못될 수 있고, 4:3·16:9 설정이 송출, 수동 영역, 미리보기에 일관되게 적용되지 않는다. 가사 모니터 설정과 정보 버튼도 실제 창이나 장치와 일치하지 않는다.

## What Changes

- 저장한 선택과 현재 연결된 출력 장치를 구분한다. 연결 변경 후에도 장치·위치·크기를 함께 확정한다.
- 표준·와이드 화면을 대상 안에 맞추고, 수동 영역과 미리보기에 같은 비율을 적용한다.
- 가사 모니터 정보와 별도 가사 창을 연결하고, PPT 썸네일은 원본 비율로 내보내 표시한다.

## Capabilities

### New Capabilities

- `winforms-monitor-layout` — WinForms 화면 선택, 가사 모니터 및 화면 비율을 정의한다.

### Modified Capabilities

해당 주 사양 없음.

## Impact

찬양·성경·PPT 송출, 운영자 미리보기, 옵션의 모니터 탭과 PPT 캐시에 적용한다. DB 스키마·동기화는 범위 밖이다. 운영 레지스트리는 비교를 위해 읽기 전용으로 조회한다.

# Spec Delta

## Purpose

WinForms에서 모니터의 연결 상태와 가로세로 비율이 달라져도 사용자가 선택한 출력과 송출이 일관되게 동작하도록 한다.

## ADDED Requirements

### Requirement: 설정 복원과 출력 모니터 선택

송출할 장치, 모드, 사각형은 같은 모니터 목록으로부터 함께 결정해야 한다(SHALL).

#### Scenario: 장치 분리와 재연결

- **WHEN** 저장한 장치가 연결되어 있지 않다.
- **THEN** 현재 연결에서 대체 장치와 그 좌표 및 양수 크기를 사용한다.
- **AND** 저장된 이름은 유지하여 재연결되면 선택을 복원한다.
- **AND** 진행 중인 관객 출력의 위치가 바뀌면 기존 송출을 정리하고 다음 시작에 새 위치를 적용한다.

#### Scenario: 선택, 싱글, 출력 없음

- **WHEN** 선택한 모니터가 연결된다.
- **THEN** 늘 첫 보조 모니터를 선택하는 대신 해당 장치를 사용한다.
- **AND** 한 대에서 싱글 모드로 실행하며 자동 모드에서 `None`을 선택하면 관객 출력 창을 열지 않는다.

### Requirement: 출력과 미리보기 비율

표준 4:3과 와이드 16:9 출력은 선택한 화면 안에 중앙 배치해야 하며, 수동 영역과 미리보기는 해당 비율을 사용해야 한다(SHALL).

#### Scenario: 와이드, 세로 모니터 및 수동 영역

- **WHEN** 현재 장치나 수동 영역을 적용한다.
- **THEN** 자동 영역은 장치 경계를 넘지 않는다.
- **AND** 수동 높이는 재시작 전후 동일하고 최소 너비에서 0이 되지 않는다.
- **AND** 수동 영역 전체가 연결된 화면 밖이면 해당 영역에서 송출을 시작하지 않는다.

### Requirement: 가사 모니터

가사 모니터 정보와 별도 가사 창은 선택한 장치를 반영해야 한다(SHALL).

#### Scenario: 선택과 비활성

- **WHEN** 장치, 미선택 또는 `None`으로 정보를 조회하거나 송출을 시작한다.
- **THEN** 이름에 해당하는 정보 또는 가사 모니터 없음이 표시된다.
- **AND** 사용 가능한 가사 영역에서만 별도 창을 열고 송출 종료 시 정리한다.

### Requirement: PPT 썸네일 원본 비율

PPT 썸네일은 슬라이드의 가로세로 비율을 유지해야 한다(SHALL).

#### Scenario: 4:3 캐시와 16:9 프레젠테이션

- **WHEN** 16:9 프레젠테이션의 썸네일을 표시한다.
- **THEN** 원본 비율로 내보낸 이미지를 16:9 틀로 배치한다.
- **AND** 기존 비율 강제 캐시는 재사용하지 않는다.

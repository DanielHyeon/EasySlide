# Design

## Context

설정은 기존 키를 사용한다. 적용 단계에서는 연결된 장치 목록, 저장한 이름, 출력 모드와 비율로 별도의 배치 결과를 만든다.

## Decisions

- 이름이 유효하면 지정 장치를 유지한다. `Auto` 또는 분리된 장치는 우선순위에 따라 대체하고 저장 이름은 보존한다. `None`은 자동 모드의 송출을 끈다. 최초 설치의 출력 기본값은 `Auto`다.
- 실제 송출 배치가 바뀌면 진행 중인 송출은 기존 종료 경로로 정리한다. 새 배치는 다음 송출에 적용한다. 가사 창만 바뀌면 관객 송출을 유지하고 가사 창을 다시 배치한다. 별도 미디어 재생도 해석된 출력 위치와 크기를 사용한다.
- 모니터 한 대에서는 싱글 모드로 실행한다. 수동 위치와 싱글 모드 옵션은 유지한다. 선택된 장치의 사각형에 4:3 또는 16:9를 중앙에 맞추고, 수동 높이는 너비에서 계산해 최소 1로 제한한다. 미리보기에도 같은 비율을 쓴다.
- 가사 창 자동 배치는 메인 출력과 다른 비주 모니터를 사용한다. `None`은 창을 열지 않는다. 정보 버튼은 목록 인덱스 대신 장치 이름을 사용한다. 기존 가사 창의 업데이트 및 정리는 WinForms UI 스레드에서 수행한다.
- PPT 내보내기는 슬라이드 크기에서 픽셀 비율을 구하고, 썸네일은 읽은 이미지 비율로 높이를 정한다. 예전 4:3 캐시는 재사용 대상에서 제외한다.

## Verification

가상 모니터 목록과 임시 이미지로 정상 진입점의 계산과 표시를 검증한다. WinForms와 WPF 테스트, Release 빌드, 운영 EasiSlides와 PowerPoint 설정의 읽기 전용 해시 비교를 실행한다.

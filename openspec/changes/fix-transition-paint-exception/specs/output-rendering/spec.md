# output-rendering

## ADDED Requirements

### Requirement: 전환 효과를 여러 번 그려도 예외가 나지 않는다

송출 화면과 그 미리보기는 전환 효과를 몇 번이든 이어서 그릴 수 있어야 한다(SHALL). 한 프레임을 그린 뒤 다음 프레임에서 쓸 그리기 자원을 해제하면 안 된다(SHALL NOT).

#### Scenario: 쇼가 꺼진 상태에서 검은 화면

- **GIVEN** 송출 단에 글자 항목이 있고 쇼는 꺼져 있다
- **WHEN** 검은 화면을 켜고, 끄고, 다시 켠다
- **THEN** 송출 화면 미리보기에 빨간 X가 나오지 않는다
- **AND** 예외 창이 뜨지 않는다

#### Scenario: 쇼가 꺼진 상태에서 글자 숨김

- **GIVEN** 송출 단에 글자 항목이 있고 쇼는 꺼져 있다
- **WHEN** 글자 숨김을 켜고 끈다
- **THEN** 빨간 X도 예외 창도 나오지 않는다

#### Scenario: 쇼 진행 중

- **GIVEN** 쇼가 진행 중이고 글자 항목이 나가고 있다
- **WHEN** 검은 화면과 글자 숨김을 켜고 끄고, 슬라이드를 여러 장 넘긴다
- **THEN** 송출 창과 메인 화면 어디에도 빨간 X나 예외 창이 나오지 않는다

#### Scenario: 자원 해제

- **WHEN** 전환 효과를 그리는 컨트롤이 해제된다
- **THEN** 그리기 자원도 함께 해제된다

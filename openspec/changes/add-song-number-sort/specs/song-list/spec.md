# song-list

## ADDED Requirements

### Requirement: 폴더의 찬양 목록을 번호순으로 정렬할 수 있다

폴더의 정렬 방식은 제목순, 글자 수순, 번호순 중 하나여야 한다(SHALL). 번호순에서는 곡 번호가 있는 곡이 번호 오름차순으로 먼저 나오고, 번호가 없는 곡은 그 뒤에 제목순으로 나와야 한다(SHALL). 고른 방식은 폴더마다 저장되어 앱을 다시 켜도 유지되어야 한다(SHALL).

#### Scenario: 새찬송가를 번호순으로 본다

- **GIVEN** 새찬송가 폴더가 제목순으로 보이고 있다
- **WHEN** 정렬 메뉴에서 "Sort by Song Number"를 고른다
- **THEN** 목록이 1장, 2장, 3장 … 순서로 바뀐다
- **AND** 곡 번호가 없는 곡은 목록의 끝에 있다

#### Scenario: 찾기 상자와 함께 쓴다

- **GIVEN** 폴더가 번호순이다
- **WHEN** 찾기 상자에 글자를 넣는다
- **THEN** 걸러진 곡들도 번호순으로 나온다

#### Scenario: 다른 폴더는 그대로다

- **WHEN** 한 폴더를 번호순으로 바꾼다
- **THEN** 다른 폴더의 정렬 방식은 바뀌지 않는다

### Requirement: 기존 정렬 방식과 전체 옵션은 달라지지 않는다

제목순과 글자 수순의 결과는 이 변경 전과 같아야 한다(SHALL). 전체 옵션 "Use Song Numbering"이 켜져 있을 때의 동작도 같아야 한다(SHALL).

#### Scenario: 전체 옵션이 켜져 있다

- **WHEN** "Use Song Numbering"이 켜져 있다
- **THEN** 모든 폴더가 지금처럼 번호순이고 폴더 정렬 버튼은 꺼져 있다

# ADR-0007: `--legacy-ui` 안전망 유지 기간 (M3까지)

* **상태**: Accepted
* **결정일**: 2026-05-27
* **결정자**: 프로젝트 메인테이너 + UI/UX 현대화 리뷰
* **태그**: rollback, safety, migration, sunset, live-operations
* **관련**: 계획서 §0.5 Q8, §8.3, §9.4, §10.5.2 · ADR-0001 (WPF)

## 컨텍스트

WinForms → WPF 마이그레이션 기간(Sprint 0~10, ~5개월) 동안 라이브 운영 환경에서 회귀 위험을 어떻게 방어할 것인가? 계획서 §9.4에 안전망 패턴 정의됨:

- 빌드 산출물 분리: `Easislides.exe` (legacy WinForms) + `EasislidesNext.exe` (신규 WPF)
- 공통 도메인 어셈블리 `Easislides.Core.dll` 추출 → 양쪽 참조
- 사용자 토글: CLI 인자 `--legacy-ui`로 신규 빌드에서도 legacy UI 호출 가능

이 안전망을 **언제까지 유지할 것인가**? Q8 결정: D-Day +6개월까지 legacy 유지보수, 그러나 **인-프로세스 토글 `--legacy-ui`는 별개의 문제**.

## 고려한 대안

### A. M3까지 (Sprint 8 end — 모든 폼 신규 완료 시점) — **채택**

| 장점 | 단점 |
|---|---|
| **모든 폼이 신규로 완성·검증된 시점** — 안전망 역할 완수 | M3~M4 사이 1 스프린트(2주) 동안 안전망 없음 |
| 코드 복잡도 감소 — 두 UI 호출 분기 제거 | — |
| 사용자가 신규 UI에 적응할 시간 충분 (Sprint 5 M2 운영자 베타 이후 12주+) | — |

### B. M4까지 (v3.0 정식 출시)

| 장점 | 단점 |
|---|---|
| 정식 출시 직전까지 안전망 | 출시 일정에 안전망 코드 정리 부담 |

| | Q8 결정 정신과 충돌 |

## 결정

**A. M3까지 (Sprint 8 end).**

세부 — **3단계 sunset 일정**:

| 시점 | 상태 | 동작 |
|---|---|---|
| **Sprint 0 ~ M3 (Sprint 8 end)** | `--legacy-ui` **활성** | 사용자가 CLI 인자로 호출 시 신규 WPF 빌드 안에서 legacy WinForms `Easislides.exe` 프로세스 호출. 백업 안전망 풀 활성. |
| **M3+0 ~ M4 (Sprint 9~10, 4주)** | `--legacy-ui` **deprecated** | 인자 인식하지만 시작 시 경고 다이얼로그 표시: "이 옵션은 v3.0 출시 후 제거됩니다. 신규 UI에서 작동하지 않는 기능이 있으면 이슈로 보고해 주세요." 여전히 legacy 실행. |
| **M4 (v3.0 출시) ~ D-Day +6개월** | `--legacy-ui` **제거** | 인자 인식 안 함. 단, **별도 다운로드로 legacy `Easislides.exe` 빌드 자체는 D-Day +6개월까지 GitHub Releases에서 제공** (계획서 §10.5.2). |
| **D-Day +6개월 이후** | EOL | legacy 빌드 다운로드 페이지에 "EOL 선언, 단순 보존" 명시. |

**별도 다운로드 보존 vs 인-프로세스 토글의 분리 이유**:
- 인-프로세스 토글 유지 = 신규 빌드 안에 legacy 코드 임베드 + 분기 로직 영구. 유지보수 비용.
- 별도 다운로드 = 신규 빌드는 깨끗, legacy는 D-Day 시점 스냅샷 그대로 보존. 새 변경 없음.

## 결과

### 긍정적
- **안전망 충분** — M3 시점에 모든 폼(40개)이 신규로 검증 완료, 베타 4 스프린트(M2 운영자 베타) 운영 후 회귀 데이터 누적
- **코드 정리 시점 명확** — Sprint 9에서 인자 deprecation 경고 추가, Sprint 10에서 분기 코드 제거
- **롤백 옵션 잔존** — D-Day +6개월까지 별도 다운로드로 legacy 빌드 접근 가능 → 신규 UI에 치명적 회귀 발견 시 사용자가 자체 다운로드 가능

### 부정적
- M3~M4 사이 1 스프린트는 안전망 없음 — 단, 이 시점은 일반 베타(M3) 진입 후 안정화 기간이므로 회귀 발생 확률 낮음 가정
- 인-프로세스 토글 제거 = 사용자가 메뉴 클릭으로 즉시 legacy 전환 못 함 → "다운로드 받아 별도 실행" 단계 필요. 라이브 중 즉시 롤백이 필요한 시나리오 발생 시 마찰.

### 중립 / 리스크
- **M3 시점 검증 기준** — 단순히 "Sprint 8이 끝났다"가 아니라 다음 게이트 통과 필수:
  - 40개 폼 모두 신규 빌드에 존재
  - M2 운영자 베타 12주+ 동안 라이브 사고 0건
  - 자동 스크린샷 회귀 테스트 100% 통과
  - 사용자 피드백 critical 이슈 0건 (10일 연속)
- 위 게이트 미통과 시 안전망을 M3.5(중간) 또는 M4로 연장 (이 ADR을 Superseded 처리, 신규 ADR 작성)

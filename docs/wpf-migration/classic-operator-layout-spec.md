# Classic Operator Layout spec

작성일: 2026-06-04
기준 창 크기: 1180x760

## 목표

WPF 첫 화면은 `FrmMain` 사용자가 새로 배우지 않아도 기본 송출을 수행할 수 있는 운영 콘솔이어야 한다. 메뉴와 명령 팔레트는 남기되, 라이브 중 자주 누르는 명령의 유일한 경로가 되면 안 된다.

## 첫 화면 영역

| 영역 | 위치 | 고정/접힘 | 역할 |
| --- | --- | --- | --- |
| 메뉴 | 최상단 | 고정 | 전체 기능 탐색, 보조 경로 |
| LiveBar | 메뉴 아래 | 상태에 따라 표시 | 현재 라이브 상태를 강하게 알림 |
| 콘텐츠 브라우저 | 좌측 상단 | 고정 | 찬양/성경/검색 |
| 예배 순서 | 좌측 하단 | 고정 | 현재 진행 큐, 선택/이동 |
| Preview 상태 | 중앙 상단 왼쪽 | 고정 | 다음에 송출할 선택 항목 |
| Output 상태 | 중앙 상단 오른쪽 | 고정 | 현재 회중에게 나가는 항목 |
| Preview/PowerPoint/Media | 중앙 본문 | 고정 | 선택 항목 미리보기와 콘텐츠별 조작 |
| 항목 이동 | 중앙 하단 | 고정 | 처음/이전/다음/마지막 |
| 라이브 운영 바 | 하단 상태바 위 | 고정, wrap 허용 | Go Live, 송출+다음, Stop Live, Black, Clear, Hide, Restore, Restart, Refresh |
| 출력 인스펙터 | 우측 | 접힘 가능 | 세부 서식/배경/전환 설정 |
| 상태바 | 최하단 | 고정 | 큐 개수, 절 위치, 상태 메시지, 출력 모니터 |

## 숨기면 안 되는 P0 명령

- Go Live
- 송출 후 다음 항목
- Stop Live
- 이전/다음 항목
- 이전/다음 절
- 이전/다음 PPT 슬라이드
- Black
- Clear
- Hide
- Restore
- Restart current item
- Output refresh

## 보조 경로로 충분한 명령

- Import/Export
- 라이브러리 관리
- 성경 버전 관리
- 외부 파일 복사/이동
- 도움말/등록/정보
- 상세 서식 프리셋 관리
- 전체 설정

## 우측 인스펙터 정책

우측 인스펙터는 접혀도 된다. 다만 접히면 사라져도 되는 것은 세부 서식과 편집성 옵션뿐이다. 라이브 안전 명령, Go Live, 송출 후 다음, 예배 순서 이동은 인스펙터에 의존하면 안 된다.

## Preview / Output 분리 정책

중앙 상단은 다음 두 상태를 동시에 보여야 한다.

- Preview 준비: 현재 선택한 항목, 종류/절 위치, Go Live 대상.
- Output 송출: 현재 라이브 상태, 송출 항목 제목, 출력 모니터.

이 둘이 같은 항목일 수도 있지만, 화면에서는 항상 별도 영역으로 읽혀야 한다.

## 1180x760 레이아웃 규칙

- 최소 창 크기는 1180x760으로 둔다.
- 고정 운영 바는 한 줄에 모두 들어가지 않으면 wrap 한다.
- 버튼 텍스트는 짧게 쓰되 접근성 이름과 툴팁으로 의미를 보강한다.
- 주요 버튼은 `MinHeight`를 유지해 터치/마우스 오조작을 줄인다.
- 카드 안에 다시 카드를 넣지 않고, 같은 영역 안에서는 구분선과 그룹 라벨을 사용한다.

## 후속 검증 시나리오

1. 예배 순서에서 다음 찬양을 선택하고 Preview 확인 후 Go Live.
2. 선택 항목을 송출하고 곧바로 다음 항목으로 이동.
3. 송출 중 Black 전환 후 Restore.
4. 현재 찬양 후렴/브릿지 라벨로 즉시 점프.
5. PowerPoint 항목에서 이전/다음 슬라이드 이동.
6. 출력이 어긋난 상황에서 Refresh로 다시 그림.

## 이번 증분 구현 지시

- XAML에서 기존 명령을 재사용한다.
- `MainViewModel` 변경은 피한다.
- 새 바인딩의 `IsChecked`에는 반드시 `Mode`를 명시한다.
- 새 인터랙티브 컨트롤은 접근성 이름 또는 보이는 텍스트를 가진다.
